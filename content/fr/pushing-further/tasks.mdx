# Exécuter des tâches

Les tâches permettent d’éviter de retaper de longues commandes dans le terminal. Elles sont très pratiques et largement utilisées. Avec npm, on les appelle des **scripts** et on les définit dans `package.json`.

<NoticeIntro lang="fr"/>

Créez un projet avec `npx @nshiab/setup-data-project`, en suivant la [leçon de configuration](/first-steps/setup), sans sélectionner de bibliothèques facultatives. Ouvrez le dossier du projet généré dans VS Code.

Copiez-collez le code suivant dans `sda/main.ts`. Ce script provient de la leçon [Récupérer des données](/pushing-further/fetch). Il récupère un fichier JSON depuis GitHub, le convertit et l’affiche dans la console.

```ts showLineNumbers filename="sda/main.ts"
const response = await fetch(
  "https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.json",
);

const data = await response.json();

console.log(data);
```

Vous avez déjà utilisé `npm run sda` pour exécuter et surveiller votre code. Voyons comment cette commande fonctionne !

Ouvrez `package.json` et trouvez l’objet **scripts**. Parmi les entrées générées, vous verrez celles-ci :

```json showLineNumbers filename="package.json (extrait des scripts)"
{
  "scripts": {
    "sda": "node --env-file-if-exists=.env --watch sda/main.ts",
    "all-tests": "vp check && vp test --passWithNoTests",
    "fix": "vp check --fix"
  }
}
```

Il s’agit d’un extrait : conservez tous les autres champs et scripts de votre fichier généré.

Quand vous lancez `npm run sda` depuis la racine du projet, npm trouve `sda` dans `scripts` et exécute la commande correspondante. Node.js charge un fichier `.env` s’il existe, exécute `sda/main.ts` et surveille les modifications pour redémarrer automatiquement.

Le script `all-tests` lance les vérifications du projet, puis ses tests. Le script `fix` applique la mise en forme et les corrections automatiques. Node.js ne vérifie pas lui-même les types TypeScript quand il exécute votre code ; utilisez les vérifications du projet pour cela.

Et si vous souhaitez exécuter le script une seule fois ? Ajoutons une commande appelée `once`. Ajoutez cette entrée dans l’objet `scripts` existant, en conservant les autres entrées :

```json filename="package.json (nouvelle entrée de scripts)"
"once": "node --env-file-if-exists=.env sda/main.ts"
```

N’oubliez pas la virgule entre les entrées voisines, puis sauvegardez le fichier ! 🙃 Si `npm run sda` est encore en cours, arrêtez-le avec `CTRL` + `C`. Ensuite, lancez :

```sh
npm run once
```

Votre code s’exécute une seule fois, puis s’arrête. Si vous changez la commande définie dans `once` plus tard, vous utiliserez toujours le même raccourci : `npm run once`.

## Conclusion

Les scripts sont utiles dans toutes sortes de projets, que ce soit pour exécuter du code, extraire des données du Web, analyser des données ou créer et publier un site web. Ils rendent ces commandes faciles à lancer, et nous les utiliserons dans les prochaines leçons et les prochains projets.

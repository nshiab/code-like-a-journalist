# Conclusion

Vous avez terminé les fondamentaux de TypeScript ! 🎉

Vous savez maintenant créer des variables, utiliser différents types de données, organiser des valeurs dans des listes et des objets, prendre des décisions avec des conditions et répéter des opérations avec des boucles. Vous savez aussi exécuter votre code avec Deno et utiliser VS Code pour repérer les erreurs.

Il est maintenant temps pour vous d'essayer le projet [Calculateur d'épargne 💸](/data-projects/saving-account-calculator). Vous combinerez les concepts de ce chapitre pour calculer l'évolution d'un solde au fil du temps, puis expérimenterez avec différents taux d'intérêt. Le projet vous explique les calculs au fur et à mesure.

Une fois le projet terminé, découvrez le prochain chapitre, [Travailler avec TypeScript](/pushing-further/functions).

# Installation

Tout d'abord, installons tout ce dont nous avons besoin.

Vous pourriez avoir besoin de droits administrateur. Si vous êtes sur votre ordinateur de travail et que vous ne les avez pas, demandez l'aide de votre service informatique.

<NoticeIntro lang="fr" />

## Éditeur de code

Le code n'est que du texte. Vous pouvez écrire votre code dans n'importe quel éditeur de texte, mais il est plus pratique d'utiliser un éditeur de code qui offre de nombreuses fonctionnalités utiles.

Vous avez de nombreuses options gratuites et intéressantes, mais la plus populaire est [Visual Studio Code](https://code.visualstudio.com/), et c'est ce que nous allons utiliser. C'est un [projet en code ouvert](https://github.com/microsoft/vscode) maintenu par Microsoft.

Téléchargez-le à partir du [site web](https://code.visualstudio.com/) et installez-le.

Une fois installé, ouvrez-le. Il devrait ressembler à ceci. Ce n'est pas grave si vous avez différents onglets ouverts.  

![Une capture d'écran de l'éditeur de code Visual Studio Code.](/assets/first-steps/setup/vscode.png)

Personnellement, je trouve que l'interface est trop petite et je l'ajuste toujours pour qu'elle soit un peu plus grande lorsque je configure une nouvelle machine. Pour ce faire, cliquez sur le menu `View => Appearance => Zoom In`.

![Une capture d'écran du menu Affichage dans VS Code.](/assets/first-steps/setup/vscode-zoom.png)

## Moteur d'exécution (runtime)

Pour que votre ordinateur comprenne TypeScript et l'exécute, vous avez besoin d'un moteur d'exécution.

Encore une fois, vous avez de nombreuses excellentes options en code ouvert, mais je trouve [Deno](https://deno.com/) particulièrement facile à utiliser. Deno est maintenu par [Deno Land Inc.](https://deno.com/company), avec Ryan Dahl comme PDG. Dahl a également créé [Node.js](https://nodejs.org/), un autre moteur très populaire.

Utilisez l'installateur officiel de Deno pour votre système d'exploitation :

- Sur macOS ou Linux, exécutez `curl -fsSL https://deno.land/install.sh | sh`.
- Sous Windows, ouvrez un terminal PowerShell et exécutez `irm https://deno.land/install.ps1 | iex`.

Vous pouvez toujours confirmer les commandes actuelles dans le [guide d'installation officiel](https://docs.deno.com/runtime/getting_started/installation/). Ce cours est testé avec la version de Deno indiquée dans la section [outils testés](https://github.com/nshiab/code-like-a-journalist#tested-course-toolchain) du dépôt. Une version plus récente de Deno 2 devrait également fonctionner. Si Deno est déjà installé, exécutez `deno upgrade` pour le mettre à jour.

![Une capture d'écran du site web de Deno.](/assets/first-steps/setup/deno.png)

Ensuite, suivez ces étapes :

1. Ouvrez un nouveau terminal dans VS Code.
2. Collez la commande correspondant à votre système d'exploitation et appuyez sur la touche Entrée pour l'exécuter.

La commande téléchargera et installera Deno sur votre ordinateur.

![Une capture d'écran montrant comment installer Deno depuis le terminal de VS Code.](/assets/first-steps/setup/deno-install.png)

Maintenant, tout devrait être correctement installé.

Quittez et redémarrez VS Code. Ensuite, tapez `deno --version` dans votre terminal et appuyez sur Entrée pour afficher votre version de Deno. Vous devriez voir quelque chose comme ceci !

![Une capture d'écran montrant comment afficher la version de Deno.](/assets/first-steps/setup/deno-version.png)

## Extensions

VS Code dispose d'un merveilleux écosystème d'extensions et l'équipe de Deno en a créé une très utile pour vous aider à coder efficacement.

Suivez ces étapes pour l'installer :

1. Cliquez sur l'onglet Extensions sur le côté gauche de VS Code.
2. Recherchez l'extension Deno.
3. Installez l'extension publiée par **Denoland**. Assurez-vous que `Mise à jour automatique` est cochée.

![Une capture d'écran montrant comment installer l'extension Deno.](/assets/first-steps/setup/deno-extension.png)

Une des fonctionnalités très pratique de l'extension Deno est son formateur de code. Mettons à jour les paramètres de VS Code pour qu'il formate automatiquement notre code à chaque sauvegarde de fichier. Cela aidera à garder tout propre et bien organisé.

- Sur Mac, allez dans `Code => Preferences => Settings`.
- Sur PC, allez dans `File => Preferences => Settings`.

![Capture d'écran montrant les paramètres de VS Code.](/assets/first-steps/setup/vscode-settings.png)

Recherchez `Default Formatter` dans la barre de recherche et sélectionnez `Deno` dans le menu déroulant.

![Capture d'écran montrant les paramètres du formateur de VS Code.](/assets/first-steps/setup/vscode-formatter.png)

Recherchez `Format On Save` et cochez la case pour l'activer.

![Capture d'écran montrant les paramètres du formatage à la sauvegarde de VS Code.](/assets/first-steps/setup/vscode-format-on-save.png)

Les paramètres sont enregistrés automatiquement, vous pouvez donc fermer l'onglet `Settings`. Tout est prêt !

L'extension est désactivée par défaut, car les projets TypeScript n'utilisent pas tous Deno. Vous l'activerez pour chaque projet Deno dans la prochaine section. VS Code utilisera alors le même serveur de langage Deno que la ligne de commande pour la vérification des types, IntelliSense, la vérification du code et le formatage.

## Exécutons un script

Pour vérifier que tout fonctionne comme prévu, nous allons écrire un petit script et l'exécuter.

Pour démarrer un nouveau projet dans VS Code, suivez ces étapes :

1. Créez un nouveau dossier quelque part sur votre ordinateur.
2. Dans VS Code, cliquez sur l'onglet Explorer.
3. Cliquez sur `Open Folder` et sélectionnez le dossier que vous venez de créer. Si on vous demande si vous faites confiance aux auteurs des fichiers, répondez "Oui" pour continuer.
4. Ouvrez la palette de commandes (`CMD` + `SHIFT` + `P` sur Mac ou `CTRL` + `SHIFT` + `P` sur PC), puis exécutez `Deno: Initialize Workspace Configuration`.

Cette dernière commande crée `.vscode/settings.json` avec `"deno.enable": true`, ce qui active l'extension Deno uniquement pour ce dossier. Répétez-la chaque fois que vous démarrez un projet Deno dans un nouveau dossier.

![Une capture d'écran montrant comment ouvrir un nouveau dossier dans VS Code.](/assets/first-steps/setup/deno-open-folder.png)

Maintenant que VS Code a ouvert votre dossier, nous pouvons créer un nouveau fichier.

1. Faites un clic droit sur l'Explorateur.
2. Cliquez sur `New File...`.
3. Nommez votre nouveau fichier `main.ts`. Si le fichier ne s'ouvre pas en tant que nouvel onglet, cliquez dessus.
4. Dans l'onglet `main.ts`, tapez `console.log("This is going to be fun!");` et enregistrez le fichier en appuyant sur `CMD` + `S` sur Mac ou `CTRL` + `S` sur PC.

Ce code dit à votre ordinateur d'afficher *This is going to be fun!* dans votre terminal.

![Une capture d'écran montrant comment créer un nouveau fichier TypeScript dans VS Code.](/assets/first-steps/setup/deno-new-file.png)

Si vous voyez un point blanc au lieu d'une croix sur l'étiquette de l'onglet (comme montré dans la capture d'écran ci-dessous), cela signifie que vous avez modifié le fichier mais ne l'avez pas encore enregistré. Assurez-vous d'enregistrer le fichier en cliquant sur son contenu puis en appuyant sur `CMD` + `S` sur Mac ou `CTRL` + `S` sur PC.

![Capture d'écran montrant un fichier non enregistré dans VS Code.](/assets/first-steps/setup/save.png)

Une fois le fichier enregistré, nous pouvons exécuter le script.

1. Affichez le terminal.
2. Tapez `deno run main.ts` dans le terminal et appuyez sur Entrée.

Cela demande à votre ordinateur d'utiliser Deno pour exécuter le script `main.ts`. Par conséquent, vous devriez voir *This is going to be fun!* dans votre terminal.

Félicitations ! Vous êtes maintenant prêt à coder. On va bien s'amuser ! 🤩

![Une capture d'écran montrant comment exécuter un fichier TypeScript dans VS Code.](/assets/first-steps/setup/deno-run.png)

## À propos de l'IA

Vous avez peut-être remarqué que nous n'avons pas installé d'outils basés sur l'intelligence artificielle, comme [GitHub Copilot](https://github.com/features/copilot).

Ces outils sont de plus en plus populaires pour les tâches de programmation et peuvent améliorer considérablement la productivité. Cependant, ils ne sont pas sans défauts. Ils peuvent introduire des erreurs et des bogues.

Pour les programmeurs expérimentés, ce n’est pas un gros problème. Quand vous savez ce que vous faites, vous pouvez facilement vérifier et ajuster ce que l'IA vous donne.

Pour les débutants, cependant, il est préférable de s'en passer. Prenez le temps de maîtriser les bases. Avec des fondations solides, vous pourrez alors exploiter pleinement le potentiel de ces outils.

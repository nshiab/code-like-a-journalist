# Running tasks

Tasks are a way to avoid rewriting long commands in the terminal. They are very convenient and widely used. With npm, we call them **scripts** and define them in `package.json`.

I assume you've completed Chapter 1 and all previous lessons in Chapter 2 before diving into this one. In particular, make sure you've followed the [Setup lesson](/first-steps/setup).

<NoticeIntro />

## Setup

Create a new, empty folder on your computer, open it with VS Code, and create a file named `main.ts` inside it.

Type this code in `main.ts` and save the file:

```ts showLineNumbers filename="main.ts"
console.log("Hello!");
```

Open the terminal (`Command` + `J` on Mac or `Control` + `J` on Windows) and run this command:

```sh
node --watch main.ts
```

This runs our code and automatically runs it again each time we save a change, so we can see the results as we work.

## Create npm scripts

Replace the contents of `main.ts` with the following code and save the file. This script comes from the [Fetching data](/pushing-further/fetch) lesson. It fetches a JSON file from GitHub, parses it, and logs it.

```ts showLineNumbers filename="main.ts"
const response = await fetch(
  "https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.json",
);

const data = await response.json();

console.log(data);
```

You've already used `node --watch main.ts` to execute and watch your code. Let's give it a shorter name!

If your folder doesn't have a `package.json`, create one by running `npm init -y` in the terminal. Stop any running watcher with `CTRL` + `C` first. `npm` comes with Node.js, so you don't need to install it separately.

Open `package.json`. Add or update its **scripts** object so it includes these entries, and set `type` to `module`. The file should look like this, with any existing dependencies and other fields kept in place:

```json showLineNumbers filename="package.json"
{
  "type": "module",
  "scripts": {
    "watch": "node --watch main.ts",
    "once": "node main.ts"
  }
}
```

The `type` setting tells Node.js that our project uses `import` and `export`. Don't forget the commas between neighboring entries, and save the file! 🙃

Now run:

```sh
npm run watch
```

npm finds `watch` inside `scripts` and executes `node --watch main.ts`. Your code runs again whenever you save it, just as before.

What if you want to run it just once? Stop the watcher with `CTRL` + `C`, then run:

```sh
npm run once
```

Your code runs once, then exits. If you later change the command stored in `once`, you'll still use the same shortcut: `npm run once`.

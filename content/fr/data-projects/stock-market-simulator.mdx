# Simulateur de marché boursier 📈

Bienvenue dans ce nouveau projet ! Nous allons récupérer des données historiques du marché boursier et les utiliser pour estimer combien nous aurions gagné ou perdu en investissant dans des entreprises cotées en bourse.

Avant de commencer, assurez-vous d'avoir terminé les sections **Fondamentaux de TypeScript** et **Travailler avec TypeScript**. Ce projet est conçu pour vous aider à pratiquer tout ce que nous avons couvert jusqu'à présent dans ce cours.

<NoticeIntro lang="fr" />

## Quelle est la question ?

Il est toujours important d'identifier clairement la question à laquelle nous voulons répondre avant de plonger trop vite dans un océan de données.

Aujourd'hui, notre question est :
- Combien aurions-nous gagné ou perdu en investissant dans une entreprise cotée en bourse à une date précise ?

Pour y répondre, nous devons calculer la différence entre le montant initial et le montant final.

Nous pouvons également identifier trois variables qui influenceront le résultat :
- L'entreprise choisie
- Le montant initial investi
- La date de l'investissement

Avec cela en tête, commençons !

### Récupération des données

Ne vous inquiétez pas, j'ai créé une fonction juste pour cela !

Nous allons installer ma librairie libre [Journalism Finance](https://github.com/nshiab/journalism-finance) et utiliser la fonction [`getYahooFinanceData`](https://jsr.io/@nshiab/journalism-finance/doc/~/getYahooFinanceData). Elle récupère les données de Yahoo Finance sous la forme d'une liste propre d'objets contenant des timestamps et des valeurs.

Mais attention : `getYahooFinanceData` utilise un point d'accès non documenté de Yahoo Finance et n'est ni affiliée à Yahoo ni approuvée par Yahoo. Il en va de même pour de nombreuses autres librairies libres que vous pourriez trouver pour récupérer ce type de données. Avant de l'utiliser, consultez les [conditions d'utilisation de Yahoo](https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html) et les [restrictions du fournisseur de données](https://help.yahoo.com/kb/finance/SLN2310.html) qui pourraient s'appliquer.

Pour l'instant, arrêtons de surveiller et d'exécuter `main.ts`. Cliquez dans le terminal et appuyez sur `CTRL` + `C`. Installez ensuite la librairie en exécutant cette commande dans le terminal :

`deno add jsr:@nshiab/journalism-finance`

Si vous ouvrez maintenant `deno.json`, vous verrez que la dépendance y figure. Cela signifie que nous pouvons l'utiliser dans notre code. Ne vous inquiétez pas de `deno.lock`. Il contient simplement des informations supplémentaires pour Deno.

![Une capture d'écran montrant la dépendance Journalism Finance installée et ajoutée à deno.json.](/assets/stock-market-simulator/install-journalism-finance.png)

Nous allons d'abord recueillir les données, puis les utiliser. Pour garder le projet bien organisé, nous placerons les fonctions utilitaires réutilisables dans leurs propres fichiers. Créez un dossier nommé `helpers`, puis ajoutez-y `getData.ts`. Cette fonction récupérera les données d'une entreprise cotée en bourse.

Dans cette première fonction utilitaire, nous importons `getYahooFinanceData` depuis `@nshiab/journalism-finance`, nous l'appelons avec les paramètres expliqués ci-dessous, puis nous retournons les données. `getData` attend un paramètre de type chaîne de caractères, `symbol`. Comme la fonction est générale, nous pourrons la réutiliser pour n'importe quelle entreprise si nécessaire.

L'ajout de `export default` nous permet d'importer la fonction là où nous en avons besoin, soit dans `main.ts` dans notre cas.

```ts showLineNumbers filename="getData.ts"
import { getYahooFinanceData } from "@nshiab/journalism-finance";

export default async function getData(symbol: string) {
  const dailyStockData = await getYahooFinanceData(
    symbol,
    new Date("1970-01-01"),
    new Date(),
    "adjclose",
    "1d",
  );

  return dailyStockData;
}
```

![Une capture d'écran montrant la fonction utilitaire getData dans VS Code.](/assets/stock-market-simulator/get-data-helper.png)

Voici les arguments que nous passons à `getYahooFinanceData` :

- `symbol` est le symbole boursier. Nous utiliserons `AAPL` pour Apple.
- Les deux dates définissent la période. Nous commençons en 1970 et terminons aujourd'hui afin d'obtenir tous les prix disponibles.
- `"adjclose"` sélectionne le prix ajusté de clôture. Celui-ci tient compte d'événements comme les fractionnements d'actions et les dividendes, ce qui le rend utile pour estimer le rendement d'un investissement.
- `"1d"` demande la valeur à la fin de chaque journée.

Notez que `getYahooFinanceData` est asynchrone parce qu'elle récupère des données sur Internet. Nous utilisons le mot-clé `await` pour nous assurer que toutes les données sont reçues avant de poursuivre l'exécution du script.

<Callout type="info" emoji="💡">
    En arrière-plan, `getYahooFinanceData` récupère des données depuis une API de Yahoo Finance. Une API, ou *Application Programming Interface*, permet à des programmes d'échanger des données. Nous verrons comment trouver des API non documentées dans le projet [Web scraping](/data-projects/web-scraping).
</Callout>

Nous pouvons maintenant mettre à jour `main.ts` pour importer et appeler notre nouvelle fonction utilitaire, tout en gardant notre code bien organisé.

À la ligne 3, nous créons la variable `symbol` et lui attribuons le symbole boursier d'Apple, `AAPL`. Nous passons cette variable à `getData`, qui attend un paramètre `symbol`. Là encore, nous utilisons `await` pour nous assurer de recevoir toutes les données avant de continuer. À la ligne 6, nous affichons les dix premiers résultats sous forme de tableau.

```ts showLineNumbers filename="main.ts"
import getData from "./helpers/getData.ts";

const symbol = "AAPL";
const dailyStockData = await getData(symbol);

console.table(dailyStockData.slice(0, 10));
```

## Mise en cache

Si nous exécutions `main.ts` maintenant, les données seraient récupérées à nouveau chaque fois que le code est exécuté.

Nous ne voulons pas surcharger les serveurs de Yahoo avec nos requêtes. Nous devons respecter leur infrastructure. Nous ne voulons pas non plus être mis sur une liste noire... 🫣 Mettons donc les données en cache.

L'idée est assez simple. La première fois que nous récupérons les données, nous les écrivons dans un fichier. Ensuite, chaque fois que le code s'exécute à nouveau, si le fichier existe, ce qui sera le cas, nous l'utilisons au lieu de récupérer les données une nouvelle fois.

Créez d'abord un nouveau dossier nommé `data`, dans lequel nous stockerons les données mises en cache.

![Une capture d'écran montrant un nouveau dossier data dans VS Code.](/assets/stock-market-simulator/create-data-folder.png)

Nous allons maintenant mettre à jour `getData` pour vérifier si un fichier mis en cache existe. Pour cela, nous utilisons `Deno.stat()`, qui retourne de l'information si le fichier existe. S'il n'existe pas, `catch()` retourne `null`. Nous pouvons ensuite utiliser des branches `if` et `else` pour lire les données depuis le fichier s'il existe, ou récupérer de nouvelles données s'il n'existe pas.

```ts showLineNumbers filename="getData.ts"
import { getYahooFinanceData } from "@nshiab/journalism-finance";

export default async function getData(symbol: string) {
  const path = `./data/${symbol}.json`;
  let dailyStockData;

  if (await Deno.stat(path).catch(() => null)) {
    console.log(`=> Cached data found at ${path}. Reading it...`);
    dailyStockData = JSON.parse(await Deno.readTextFile(path));
  } else {
    console.log("=> No cached data found. Fetching it from Yahoo Finance...");
    dailyStockData = await getYahooFinanceData(
      symbol,
      new Date("1970-01-01"),
      new Date(),
      "adjclose",
      "1d",
    );
    console.log(`=> Data fetched. Writing it to ${path} for the next run...`);
    await Deno.writeTextFile(path, JSON.stringify(dailyStockData));
  }

  return dailyStockData;
}
```

<Callout type="info" emoji="💡">
    `catch()` permet de capturer les erreurs déclenchées par votre code. Nous l'explorerons plus en détail dans la leçon [Gérer les erreurs avec `try` et `catch`](/ninja-moves/try-catch). Ne vous en préoccupez pas pour l'instant. Nous y reviendrons plus tard.
</Callout>

Voici ce qui se passe lorsque vous exécutez ce code :

- À la ligne 4, `path` contient l'emplacement et le nom du fichier mis en cache. Nous y incluons `symbol` afin que chaque entreprise ait son propre fichier et que ses données ne soient pas écrasées.
- À la ligne 5, `dailyStockData` est une variable `let`, car elle recevra soit les données mises en cache, soit de nouvelles données de Yahoo Finance.
- À la ligne 7, `Deno.stat()` vérifie si le fichier existe.
- S'il existe, la ligne 8 indique dans le terminal que des données mises en cache ont été trouvées et affiche le chemin du fichier. La ligne 9 lit ensuite le fichier et reconvertit son texte en une liste d'objets.
- Sinon, la ligne 11 indique dans le terminal qu'aucune donnée mise en cache n'a été trouvée et que de nouvelles données seront récupérées depuis Yahoo Finance. Les lignes 12 à 18 les récupèrent ensuite.
- Une fois les nouvelles données reçues, la ligne 19 indique où elles seront enregistrées pour la prochaine exécution. La ligne 20 convertit la liste en texte et l'écrit dans ce fichier.
- Enfin, la ligne 23 retourne `dailyStockData`, que les données proviennent du cache ou de Yahoo Finance.

Exécutez maintenant `main.ts`, surveillez les changements et activez toutes les permissions :

`deno -A --watch --check main.ts`

La première fois que vous exécutez ce code, Deno ne trouvera pas de fichier nommé `AAPL.json`. Le bloc `if` des lignes 8 et 9 ne sera donc pas exécuté. Ce sont plutôt les lignes 11 à 20 sous `else` qui le seront. Vous verrez les deux messages dans le terminal et la ligne 20 créera `AAPL.json` dans le dossier `data`.

![Une capture d'écran montrant les données boursières récupérées et écrites dans AAPL.json.](/assets/stock-market-simulator/data-fetched-aapl.png)

<Callout type="info" emoji="💡">
    Vous vous demandez ce que signifie `timestamp` ? Cet énorme nombre correspond au nombre de millisecondes écoulées depuis le 1er janvier 1970. C'est ainsi que JavaScript suit les dates et les heures en arrière-plan. Ici, la librairie nous fournit directement le timestamp plutôt qu'une date, mais comme nous le verrons, JavaScript permet de passer facilement des dates aux timestamps et vice versa.
</Callout>

Exécutez de nouveau `main.ts` en l'enregistrant (`CMD` + `S` sur Mac ou `CTRL` + `S` sur PC). Cette fois, la condition de la ligne 7 est remplie, car Deno trouve `AAPL.json`. Les lignes 8 et 9 sont exécutées, tandis que tout ce qui se trouve sous `else` est ignoré. Nous n'avons pas besoin de récupérer les données à nouveau. Nous les lisons plutôt depuis notre fichier local. C'est plus rapide et cela évite d'importuner les serveurs de Yahoo avec une autre requête.

## Calcul des rendements

Nous avons maintenant tout ce qu'il nous faut pour calculer les rendements !

Créons une autre fonction, `calculateFinalAmount`, dans `helpers`. Cette fonction aura besoin de trois paramètres :
- Le montant investi, `amount`, qui doit être un `number`
- La date de l'investissement, `startDate`, qui est une `Date`
- Les données `dailyStockData` retournées par `getYahooFinanceData`, soit une liste d'objets associant un `timestamp` à une `value`

```ts showLineNumbers filename="calculateFinalAmount.ts"
export default function calculateFinalAmount(
  amount: number,
  startDate: Date,
  dailyStockData: { timestamp: number; value: number }[],
) {
  console.log("=> Calculating final amount...");

  const filteredDailyStockData = dailyStockData.filter((dailyData) =>
    dailyData.timestamp >= startDate.getTime()
  );

  const initialValue = filteredDailyStockData[0].value;
  const finalValue = filteredDailyStockData[filteredDailyStockData.length - 1]
    .value;
  const rateOfReturn = (finalValue - initialValue) / initialValue;

  return amount + amount * rateOfReturn;
}
```

Voici ce qui se passe lorsque nous appelons cette fonction :

- La ligne 6 indique dans le terminal que la fonction est appelée.
- Les lignes 8 à 10 conservent uniquement les données à partir de la date de l'investissement.
- La ligne 12 récupère la valeur initiale de l'action.
- Les lignes 13 et 14 récupèrent sa valeur la plus récente.
- La ligne 15 calcule le taux de rendement, qui peut être positif ou négatif.
- La ligne 17 calcule le montant final : le montant initial auquel s'ajoute le montant multiplié par le taux de rendement.

Si nous exécutons notre code maintenant, rien ne se produira. Nous devons encore appeler notre nouvelle fonction dans `main.ts`.

Nous importons d'abord `calculateFinalAmount`. Ensuite, nous créons les variables `amount` et `startDate`, puis nous les passons à la fonction avec `dailyStockData`. Enfin, nous stockons son résultat dans une nouvelle variable nommée `finalAmount`.

```ts showLineNumbers filename="main.ts" {2, 5-6, 10, 12}
import getData from "./helpers/getData.ts";
import calculateFinalAmount from "./helpers/calculateFinalAmount.ts";

const symbol = "AAPL";
const amount = 1000;
const startDate = new Date("2020-01-01");

const dailyStockData = await getData(symbol);

const finalAmount = calculateFinalAmount(amount, startDate, dailyStockData);

console.log(finalAmount);
```

Et voici le résultat ! Ça fonctionne ! Vous auriez environ 4 639 $ aujourd'hui, en septembre 2026, si vous aviez investi 1 000 $ dans Apple en janvier 2020.

## Affichage du résultat

Créons une fonction pour afficher le résultat plus clairement.

Dans `helpers`, créez une fonction appelée `logResult`.

Pour rendre le message plus facile à lire, nous formatons `startDate` avec `.toLocaleDateString("en-US")`. `"en-US"` est ce que nous appelons une locale. Elle précise que la date doit être formatée en anglais pour les États-Unis, mais vous pouvez utiliser la locale de votre choix, comme `"fr-CA"` pour le français au Canada. Nous arrondissons également `finalAmount` avec `Math.round()`.

```ts showLineNumbers filename="logResult.ts"
export default function logResult(
  amount: number,
  symbol: string,
  startDate: Date,
  finalAmount: number,
) {
  const formattedDate = startDate.toLocaleDateString("en-US");
  const roundedAmount = Math.round(finalAmount);

  console.log(
    `\nIf you had invested $${amount} in ${symbol} on ${formattedDate}, you would have $${roundedAmount} today.\n`,
  );
}
```

Nous pouvons maintenant utiliser cette fonction dans `main.ts`.

```ts showLineNumbers filename="main.ts" {3, 13}
import getData from "./helpers/getData.ts";
import calculateFinalAmount from "./helpers/calculateFinalAmount.ts";
import logResult from "./helpers/logResult.ts";

const symbol = "AAPL";
const amount = 1000;
const startDate = new Date("2020-01-01");

const dailyStockData = await getData(symbol);

const finalAmount = calculateFinalAmount(amount, startDate, dailyStockData);

logResult(amount, symbol, startDate, finalAmount);
```

## Un instant...

Tout fonctionne bien avec une `startDate` en janvier 2020... Mais que se passerait-il si la date de début était en 1970, avant l'entrée en bourse d'Apple ?

C'est impossible ! Notre code devrait avertir la personne qui l'utilise.

Remplacez `startDate` par `"1950-01-01"` pour faire un test... Le code retourne un montant, alors qu'il devrait déclencher une erreur ! 😱

![Une capture d'écran de VS Code montrant un résultat d'investissement impossible pour une date antérieure à l'entrée en bourse d'Apple.](/assets/stock-market-simulator/impossible-result.png)

Écrasons ce bogue ! 🐛

Nous pouvons mettre à jour `calculateFinalAmount`, qui reçoit déjà `startDate` et `dailyStockData`. Les lignes que nous ajoutons ci-dessous comparent la date de l'investissement au premier prix disponible. Si la date de l'investissement est antérieure, la fonction déclenche une erreur accompagnée d'un message.

```ts showLineNumbers filename="calculateFinalAmount.ts" {8-12}
export default function calculateFinalAmount(
  amount: number,
  startDate: Date,
  dailyStockData: { timestamp: number; value: number }[],
) {
  console.log("=> Calculating final amount...");

  if (startDate.getTime() < dailyStockData[0].timestamp) {
    throw new Error(
      "The company was not public at that time. Please choose a later date.",
    );
  }

  const filteredDailyStockData = dailyStockData.filter((dailyData) =>
    dailyData.timestamp >= startDate.getTime()
  );

  const initialValue = filteredDailyStockData[0].value;
  const finalValue = filteredDailyStockData[filteredDailyStockData.length - 1]
    .value;
  const rateOfReturn = (finalValue - initialValue) / initialValue;

  return amount + amount * rateOfReturn;
}
```

![Une capture d'écran montrant une erreur déclenchée depuis calculateFinalAmount.](/assets/stock-market-simulator/error.png)

<Callout type="info" emoji="💡">
    Déclencher une erreur arrête le script et fournit, espérons-le, un message utile. L'erreur indique également son origine. Dans la capture d'écran ci-dessus, `calculateFinalAmount.ts:9:11` désigne la ligne 9 et le caractère 11 de ce fichier. Dans VS Code, faites `CMD` + clic sur cette référence pour accéder directement à l'erreur, ce qui est très pratique pour déboguer.
</Callout>

C'est mieux. Nous ne retournerons plus de résultats impossibles ! Vous pouvez maintenant essayer différentes valeurs pour `startDate` en toute sécurité.

Mais sommes-nous complètement à l'abri ? Que se passe-t-il si vous fournissez une date dans le futur ? 🤔 Essayez de trouver un moyen de déclencher une autre erreur dans ce cas. Voici un indice : `Date.now()` vous donne la date et l'heure actuelles sous la forme d'un nombre de millisecondes.

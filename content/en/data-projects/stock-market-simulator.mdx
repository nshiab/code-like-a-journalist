# Stock market simulator 📈

Welcome to this new project! We are going to fetch historical stock market data and use it to estimate how much we would have gained or lost by investing in publicly traded companies.

Here's what the project will look like in the end. The screenshot below shows an example result for investing $1,000 in Apple in January 2020. When you run the project, it fetches the latest available market data, so your final amount will change over time.

Before starting, make sure you have completed the **TypeScript fundamentals** and **Working with TypeScript** sections. This project is designed to help you practice everything we've covered so far in this course.

## What's the question?

It's always important to clearly identify the question we want to answer before diving too fast into an ocean of data.

So, today, our question is:
- How much would we have gained or lost by investing in a given publicly traded company on a specific date?

To answer this, we need to calculate the difference between the initial amount and the final amount.

We can also identify three variables that will impact the result:
- The chosen company
- The initial amount of money
- The date of the investment

With this in mind, let's start!

Create a new folder with:

### Fetching the data

Don't worry, I created a function just for that!

We're going to install my open-source [Journalism Finance](https://github.com/nshiab/journalism-finance) library and use the [`getYahooFinanceData`](https://jsr.io/@nshiab/journalism-finance/doc/~/getYahooFinanceData) function. It fetches Yahoo Finance data as a clean array of objects containing timestamps and values.

But be careful: `getYahooFinanceData` uses an undocumented Yahoo Finance endpoint and is not affiliated with or endorsed by Yahoo. The same is true of many other open-source libraries you might find for retrieving this kind of data. Before using it, review [Yahoo's terms](https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html) and any applicable [data-provider restrictions](https://help.yahoo.com/kb/finance/SLN2310.html).

For now, let's stop watching and running `main.ts` by clicking in the terminal and pressing `CTRL` + `C`. Then, install the library by running this command in the terminal:

`deno add jsr:@nshiab/journalism-finance`

If you open `deno.json` now, you'll see the dependency listed in it. This means we can use it in our code. Don't worry about `deno.lock`. It just contains extra information for Deno.

![A screenshot showing the Journalism Finance dependency installed and added to deno.json.](/assets/stock-market-simulator/install-journalism-finance.png)

We'll first gather the data, then use it. To keep the project organized, we'll put reusable helper functions in their own files. Create a folder called `helpers`, then add `getData.ts`. This function will retrieve data for a publicly traded company.

In this first helper, we import `getYahooFinanceData` from `@nshiab/journalism-finance`, call it with parameters explained below, and return the data. `getData` expects one string parameter, `symbol`. Because the function is general, we can reuse it for any company if needed.

Adding `export default` lets us import the helper where we need it, which in this case will be `main.ts`.

```ts showLineNumbers filename="getData.ts"
import { getYahooFinanceData } from "@nshiab/journalism-finance";

export default async function getData(symbol: string) {
  const dailyStockData = await getYahooFinanceData(
    symbol,
    new Date("1970-01-01"),
    new Date(),
    "adjclose",
    "1d",
  );

  return dailyStockData;
}
```

![A screenshot showing the getData helper function in VS Code.](/assets/stock-market-simulator/get-data-helper.png)

Here are the arguments we pass to `getYahooFinanceData`:

- `symbol` is the stock market symbol. We will use `AAPL` for Apple.
- The two dates define the period. We start in 1970 and finish today so we get all available prices.
- `"adjclose"` selects the adjusted closing price. It accounts for events such as stock splits and dividends, making it useful for estimating investment returns.
- `"1d"` asks for the value at the end of each day.

Note that `getYahooFinanceData` is asynchronous because it fetches data over the Internet. We use the `await` keyword to make sure all the data is received before the rest of the script runs.

<Callout type="info" emoji="💡">
    Under the hood, `getYahooFinanceData` fetches data from a Yahoo Finance API. An API, or *Application Programming Interface*, allows programs to exchange data. We will explore how to find undocumented APIs in the [Web scraping](/data-projects/web-scraping) project.
</Callout>

Now, we can update `main.ts` to import and call our new helper, keeping our code clean.

On line 3, we create the `symbol` variable and assign Apple's stock market symbol, `AAPL`, to it. We pass this variable to `getData`, which expects a `symbol` parameter. Again, we use `await` to make sure we receive all the data before continuing. On line 6, we log the first ten results as a table.

```ts showLineNumbers filename="main.ts"
import getData from "./helpers/getData.ts";

const symbol = "AAPL";
const dailyStockData = await getData(symbol);

console.table(dailyStockData.slice(0, 10));
```

## Caching

If we were to run `main.ts` right now, the data would be refetched every time the code is executed.

We don’t want to overwhelm Yahoo’s servers with our requests. We must respect their infrastructure. Also, we don’t want to get blacklisted... 🫣 So let's cache the data.

The idea is pretty simple. The first time we fetch the data, we write it to a file. Then, every time the code runs again, if the file exists (which it will), we use it instead of fetching the data again.

To check whether the file already exists on our machine, we can use the `exists` function from Deno's standard library [@std/fs](https://jsr.io/@std/fs/doc/~/exists) (*fs* stands for *file system*).

Install it by running: `deno add jsr:@std/fs`.

Create a new folder called `data`, where we will store the cached data.

Now, update `getData.ts` to check whether a cached file exists. If it does, the function reads and returns it. Otherwise, it calls `getYahooFinanceData`, saves the returned array, and returns it.

The code below handles caching. Here’s what happens when you run it:

- Lines 1–2 import the two library functions we need.
- Line 5 uses `symbol` to create a different cache path for each company.
- Line 8 checks whether that file already exists.
- If it does, lines 9–10 read and parse its JSON.
- If it doesn't, lines 13–21 fetch the data and write it to the cache.
- Line 24 returns the data, no matter where it came from.

```ts showLineNumbers filename="getData.ts"
import { exists } from "@std/fs";
import { getYahooFinanceData } from "@nshiab/journalism-finance";

export default async function getData(symbol: string) {
  const path = `data/${symbol}.json`;
  let dailyStockData: { timestamp: number; value: number }[];

  if (await exists(path)) {
    console.log("=> Retrieving data from cache...");
    dailyStockData = JSON.parse(await Deno.readTextFile(path));
  } else {
    console.log("=> Fetching data...");
    dailyStockData = await getYahooFinanceData(
      symbol,
      new Date("1970-01-01"),
      new Date(),
      "adjclose",
      "1d",
    );
    await Deno.writeTextFile(path, JSON.stringify(dailyStockData));
  }

  return dailyStockData;
}
```

Now, run and watch `main.ts` with all permissions enabled:

`deno -A --watch --check main.ts`

The first time you run this code, you'll see the fetching message in the terminal, and a new file named `AAPL.json` will be created in `data`.

The data has been fetched and written to a file for future use. If you're curious, you can check what's inside `AAPL.json`!

If you rerun `main.ts` by saving it again, you'll see the cache message instead. The data is no longer fetched; it is read from the local file.

You can keep cached data for multiple companies. For example, replace `AAPL` in the `symbol` variable with `GOOG` to get the historical stock prices of Alphabet (formerly Google) and run the code.

You'll see another file, `GOOG.json`, being created in `data`.

If you switch back to `AAPL`, the data is still there. No need to fetch it again!

And if you want more up-to-date prices, just delete the files in `data` and rerun your code. Easy!

<Callout type="info" emoji="💡">
    Here, we are using caching to avoid pinging Yahoo's servers too many times. But caching is also very commonly used to improve performance. Reading a local file is much faster than fetching data over the Internet.
</Callout>

## Calculating returns

We now have everything we need to calculate returns!

Let's create another function, `getFinalAmount`, in `helpers`. This function will need three parameters:
- The `amount` invested, which must be a `number`
- The `startDate`, which is the `Date` of the investment
- The `dailyStockData` returned by `getYahooFinanceData`, which is an array of objects pairing a `timestamp` with a `value`

First, we filter the data to keep only prices on or after the investment date. Because the library returns timestamps in milliseconds, we can compare them directly with `startDate.getTime()`.

Then, we retrieve the first and last stock prices from the filtered data. The rate of return is the difference between those two prices, divided by the initial price. Finally, we apply that rate to the amount invested.

For example, if the adjusted stock price doubled, the rate of return would be `1`, or 100%, and our investment would also double.

```ts showLineNumbers filename="getFinalAmount.ts"
export default function getFinalAmount(
  amount: number,
  startDate: Date,
  dailyStockData: { timestamp: number; value: number }[],
) {
  console.log("=> Calculating final amount...");

  const filteredDailyStockData = dailyStockData.filter((dailyData) =>
    dailyData.timestamp >= startDate.getTime()
  );

  const initialValue = filteredDailyStockData[0].value;
  const finalValue = filteredDailyStockData[filteredDailyStockData.length - 1]
    .value;
  const rateOfReturn = (finalValue - initialValue) / initialValue;

  return amount + amount * rateOfReturn;
}
```

In `main.ts`, we can create variables `amount` and `startDate` to store the initial amount invested and the date of the investment, then pass them to our new function.

We store the result of the function `getFinalAmount` in a new variable called `finalAmount`.

```ts showLineNumbers filename="main.ts" {2, 6-7, 11}
import getData from "./helpers/getData.ts";
import getFinalAmount from "./helpers/getFinalAmount.ts";

const symbol = "AAPL";
const amount = 1000;
const startDate = new Date("2020-01-01");

const dailyStockData = await getData(symbol);

const finalAmount = getFinalAmount(amount, startDate, dailyStockData);

console.log(finalAmount);
```

And here's the result! It works! You would have $3,266 today (as of Feb. 2025) if you had invested $1,000 in Apple in January 2020.

## The results

Let's create a function to better log the results.

In `helpers`, create the function `logResult`.

For the `startDate`, we can convert it to text using `.toISOString()`, which returns the investment date in this format: `"2020-01-01T00:00:00.000Z"`. To keep only the date, we split the text on `"T"`. The `.split()` method returns an array: `["2020-01-01", "00:00:00.000Z"]`. Since we only need the date, we use the index `[0]`.

```ts showLineNumbers filename="logResult.ts"
export default function logResult(
  amount: number,
  symbol: string,
  startDate: Date,
  finalAmount: number,
) {
  console.log(
    `\nIf you had invested $${amount} in ${symbol} on ${
      startDate.toISOString().split("T")[0]
    }, you would have $${Math.round(finalAmount)} today.\n`,
  );
}
```

We can now use this function in `main.ts`.

```ts showLineNumbers filename="main.ts" {3, 13}
import getData from "./helpers/getData.ts";
import getFinalAmount from "./helpers/getFinalAmount.ts";
import logResult from "./helpers/logResult.ts";

const symbol = "AAPL";
const amount = 1000;
const startDate = new Date("2020-01-01");

const dailyStockData = await getData(symbol);

const finalAmount = getFinalAmount(amount, startDate, dailyStockData);

logResult(amount, symbol, startDate, finalAmount);
```

Beautiful, isn't it? 😍

## Wait a minute...

Everything works fine with a `startDate` of January 2020... But what would happen if the start date was in 1970, before Apple was publicly traded?

That's impossible! Our code should warn the user.

Update `startDate` to `"1950-01-01"` to test it out... It's returning an amount, but it should be throwing an error.

We can update `main.ts` to compare the `startDate` with the first timestamp in `dailyStockData`. If the investment date is earlier than the first available price, we throw an error with a message.

```ts showLineNumbers filename="main.ts" {7, 11-15}
import getData from "./helpers/getData.ts";
import getFinalAmount from "./helpers/getFinalAmount.ts";
import logResult from "./helpers/logResult.ts";

const symbol = "AAPL";
const amount = 1000;
const startDate = new Date("1950-01-01");

const dailyStockData = await getData(symbol);

if (startDate.getTime() < dailyStockData[0].timestamp) {
  throw new Error(
    "The company was not public at that time. Please choose a later date.",
  );
}

const finalAmount = getFinalAmount(amount, startDate, dailyStockData);

logResult(amount, symbol, startDate, finalAmount);
```
<Callout type="info" emoji="💡">
    Throwing errors is very useful to stop running your script and provide a message to the user (or yourself). Always aim for clear messages that will help you debug easily or will help the user to act accordingly.
</Callout>

That's better. We won't return impossible results now! You can safely play with different `startDate` values.

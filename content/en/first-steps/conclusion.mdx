# Conclusion

You’ve reached the end of TypeScript fundamentals! 🎉

You can now create variables, work with different data types, organize values in arrays and objects, make decisions with conditions, and repeat operations with loops. You also know how to run your code with Deno and use VS Code to spot errors.

It's now time for you to try the [Savings calculator 💸](/data-projects/saving-account-calculator) project. You'll combine the concepts from this chapter to calculate how a balance changes over time, then experiment with different interest rates. The project walks you through the calculations as you go.

Once you're done with the project, check out the next chapter, [Working with TypeScript](/pushing-further/functions).

# Utiliser des bibliothèques

Des millions de personnes à travers le monde travaillent avec JavaScript et TypeScript. L'une des raisons de leur popularité est l'immense écosystème de bibliothèques. De nombreux développeurs partagent leur code publiquement, ce qui permet à tout le monde de l'utiliser gratuitement.

Dans les prochaines leçons, nous utiliserons des bibliothèques en code ouvert pour analyser d'énormes ensembles de données et créer de superbes visualisations.

Une note sur le vocabulaire : les *bibliothèques* sont aussi souvent appelées *libraries*, *packages* ou *modules*.

Notez que je suppose que vous avez terminé la [leçon d'installation](/first-steps/setup) avant de vous lancer dans celle-ci.

<NoticeIntro lang="fr"/>

## Configuration

Créez un nouveau dossier vide sur votre ordinateur, ouvrez-le avec VS Code et créez-y un fichier nommé `main.ts`.

Tapez ce code dans `main.ts` et enregistrez le fichier :

```ts showLineNumbers filename="main.ts"
console.log("Hello!");
```

Ouvrez le terminal (`Command` + `J` sur Mac ou `Control` + `J` sur Windows) et exécutez cette commande :

```sh
node --watch main.ts
```

Cette commande exécute notre code et le relance automatiquement chaque fois que nous enregistrons une modification, pour voir les résultats au fur et à mesure que nous travaillons.

## Le registre npm

Les bibliothèques sont publiées sur des registres publics. Dans ce cours, nous les installerons depuis [npm](https://www.npmjs.com/), le registre utilisé par la commande npm fournie avec Node.js. Les pages des paquets présentent la documentation, les responsables, les versions et les téléchargements pour vous aider à choisir une bibliothèque.

Prenons un exemple et recherchons `d3`, une bibliothèque bien connue pour la visualisation de données que nous utiliserons fréquemment.

Allez sur [npmjs.com](https://www.npmjs.com/) et recherchez `d3`.

![Une capture d'écran montrant les résultats de NPM pour d3.](/assets/pushing-further/libraries/d3-npm.png)

Sélectionnez le premier résultat : `d3` avec la description **"Data-Driven Documents"** par Mike Bostock.

Voici [le lien direct](https://www.npmjs.com/package/d3), au cas où.

![Une capture d'écran montrant la description de d3 sur NPM.](/assets/pushing-further/libraries/d3-description.png)

Cette page fournit de nombreuses informations utiles :
- Dans la section principale, on voit une courte description et des liens vers la documentation, des exemples, et plus encore.
- Sur la droite, il y a un lien vers la page GitHub et le site officiel de la bibliothèque.
- On peut voir le nombre de téléchargements hebdomadaires, indiquant la popularité de la bibliothèque.
- La liste des responsables inclut **Mike Bostock** et **Philippe Rivière**, deux experts bien connus en visualisation de données.

Ces détails (ainsi que ceux sur la page GitHub) nous aident à déterminer si une bibliothèque est fiable. Soyez toujours prudent avant d'exécuter du code inconnu ! 🦠

Avant d'installer une librairie, créons un fichier `package.json` pour garder la liste des librairies du projet. Arrêtez la surveillance avec `CTRL` + `C`, puis exécutez ces commandes dans le dossier du projet :

```sh
npm init -y
npm pkg set type=module
```

`npm` est fourni avec Node.js. La première commande crée `package.json` ; la deuxième indique à Node.js que le projet utilise `import` et `export`. Si ce dossier contient déjà un `package.json`, sautez `npm init -y` et gardez son contenu.

Installer `d3` est très simple. Cliquez sur votre terminal, arrêtez le script (`CTRL` + `C`), puis exécutez ces commandes depuis la racine du projet :

```sh
npm install d3
npm install --save-dev @types/d3
```

La première commande installe la bibliothèque. La seconde installe ses définitions de types TypeScript pour que VS Code comprenne ses fonctions. Certaines bibliothèques incluent leurs types ; `d3` utilise le paquet séparé `@types/d3`.

Ouvrez `package.json` : `d3` figure maintenant dans **dependencies** et `@types/d3` dans **devDependencies**. Les dépendances sont les paquets utilisés par votre code ; les dépendances de développement servent aux outils, comme la vérification des types.

npm met aussi à jour `package-lock.json`, qui indique les versions exactes installées, et place les paquets dans un dossier `node_modules`. Conservez `package.json` et `package-lock.json` avec votre projet. Si vous partagez votre code, d’autres pourront lancer `npm ci` pour installer les versions du fichier de verrouillage.

<OutdatedScreenshot src="/assets/pushing-further/libraries/d3-add.png" alt={"Une capture d'écran montrant les imports dans deno.json."} lang="fr" />

<Callout type="info" emoji="💡">
    Vous n’avez pas besoin de modifier les fichiers dans `node_modules` ni de gérer le cache de téléchargement de npm. npm s’occupe de l’installation. Utilisez `npm install` pour ajouter une bibliothèque et importez-la par son nom, comme `"d3"`.
</Callout>

Reprenons le [fichier CSV des températures de Montréal](https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.csv) de la leçon [Récupérer des données](/pushing-further/fetch).

Si vous récupérez ces données, vous remarquerez que c'est juste du texte. CSV signifie **Comma-Separated Values** (valeurs séparées par des virgules) et vous ne pouvez pas travailler avec directement. Il serait bien mieux de le convertir en une liste d'objets.

Modifiez `main.ts` avec le code ci-dessous, puis exécutez la commande suivante : `node --watch main.ts`

```ts showLineNumbers filename="main.ts"
const response = await fetch(
  "https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.csv",
);

const data = await response.text();

console.log(data);
```

<OutdatedScreenshot src="/assets/pushing-further/libraries/d3-text.png" alt={"Une capture d'écran montrant des données CSV dans le terminal."} lang="fr" />

C'est notre jour de chance : la fonction `csvParse` de `d3` convertit les données CSV en une liste d'objets !

Mettons à jour notre code pour l'utiliser.

```ts showLineNumbers filename="main.ts" {1, 8, 10}
import { csvParse } from "d3";

const response = await fetch(
  "https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.csv",
);

const data = await response.text();
const arrayOfObjects = csvParse(data);

console.log(arrayOfObjects);
```
<OutdatedScreenshot src="/assets/pushing-further/libraries/d3-parse.png" alt={"Une capture d'écran montrant des données CSV converties en une liste d'objets dans le terminal."} lang="fr" />

<Callout type="info" emoji="💡">
    Dans la [leçon sur les fonctions](/pushing-further/functions), nous avons vu que nous pouvons importer des fonctions avec la syntaxe `import myFunction from "./myFunction.ts"`. Ici, c'est un peu différent, car `d3` exporte plusieurs fonctions, et nous choisissons uniquement celle(s) que nous voulons. Pour cela, nous utilisons des accolades avec cette syntaxe : `import { myFunctionA, myFunctionB } from "./allMyFunctions.ts"`.
</Callout>

Félicitations ! Vous venez d’installer `d3` depuis NPM et d’utiliser l’une de ses fonctions ! 💃🕺

## Une autre bibliothèque : csv-parse

Plusieurs bibliothèques peuvent souvent résoudre le même problème. Essayons [`csv-parse`](https://csv.js.org/parse/), une bibliothèque spécialisée dans la lecture des fichiers CSV. Sa documentation présente les interfaces disponibles, les options, des exemples et un lien vers le code source.

Arrêtez le script avec `CTRL` + `C`, puis installez-la :

```sh
npm install csv-parse
```

Ce paquet inclut ses types TypeScript : aucun paquet `@types` supplémentaire n’est nécessaire.

Nous utiliserons l’[interface synchrone](https://csv.js.org/parse/api/sync/), pratique quand le fichier CSV tient entièrement en mémoire. Importez `parse` depuis `"csv-parse/sync"`. L’[option `columns: true`](https://csv.js.org/parse/options/columns/) utilise la première ligne comme noms des propriétés au lieu d’en faire une ligne de données.

Remplacez le code de `main.ts` par ceci, puis relancez `node --watch main.ts` :

```ts showLineNumbers filename="main.ts" {1, 8}
import { parse } from "csv-parse/sync";

const response = await fetch(
  "https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.csv",
);

const data = await response.text();
const arrayOfObjects = parse(data, { columns: true });

console.log(arrayOfObjects);
```

Comme `csvParse`, cette fonction transforme le texte en liste d’objets. Par défaut, les valeurs restent du texte : convertissez les champs numériques avant de faire des calculs.

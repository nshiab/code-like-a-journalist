# Stock market simulator 📈

Welcome to this new project! We are going to fetch historical stock market data and use it to estimate how much we would have gained or lost by investing in publicly traded companies.

Before starting, make sure you have completed the **TypeScript fundamentals** and **Working with TypeScript** sections. This project is designed to help you practice everything we've covered so far in this course.

<NoticeIntro />

## What's the question?

It's always important to clearly identify the question we want to answer before diving too fast into an ocean of data.

So, today, our question is:
- How much would we have gained or lost by investing in a given publicly traded company on a specific date?

To answer this, we need to calculate the difference between the initial amount and the final amount.

We can also identify three variables that will impact the result:
- The chosen company
- The initial amount of money
- The date of the investment

With this in mind, let's start!

## Setup

Create a new folder with:
- A `main.ts` file containing `console.log("Hello!");`
- `deno.json`, used to configure Deno and activate its VS Code extension. We will keep it empty for now.

Run `deno --watch --check main.ts`. This first script does not need any special permissions.

### Fetching the data

Don't worry, I created a function just for that!

We're going to install my open-source [Journalism Finance](https://github.com/nshiab/journalism-finance) library and use the [`getYahooFinanceData`](https://jsr.io/@nshiab/journalism-finance/doc/~/getYahooFinanceData) function. It fetches Yahoo Finance data as a clean array of objects containing timestamps and values.

But be careful: `getYahooFinanceData` uses an undocumented Yahoo Finance endpoint and is not affiliated with or endorsed by Yahoo. The same is true of many other open-source libraries you might find for retrieving this kind of data. Before using it, review [Yahoo's terms](https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html) and any applicable [data-provider restrictions](https://help.yahoo.com/kb/finance/SLN2310.html).

For now, let's stop watching and running `main.ts` by clicking in the terminal and pressing `CTRL` + `C`. Then, install the library by running this command in the terminal:

`deno add jsr:@nshiab/journalism-finance`

If you open `deno.json` now, you'll see the dependency listed in it. This means we can use it in our code. Don't worry about `deno.lock`. It just contains extra information for Deno.

![A screenshot showing the Journalism Finance dependency installed and added to deno.json.](/assets/stock-market-simulator/install-journalism-finance.png)

We'll first gather the data, then use it. To keep the project organized, we'll put reusable helper functions in their own files. Create a folder called `helpers`, then add `getData.ts`. This function will retrieve data for a publicly traded company.

In this first helper, we import `getYahooFinanceData` from `@nshiab/journalism-finance`, call it with parameters explained below, and return the data. `getData` expects one string parameter, `symbol`. Because the function is general, we can reuse it for any company if needed.

Adding `export default` lets us import the helper where we need it, which in this case will be `main.ts`.

```ts showLineNumbers filename="getData.ts"
import { getYahooFinanceData } from "@nshiab/journalism-finance";

export default async function getData(symbol: string) {
  const dailyStockData = await getYahooFinanceData(
    symbol,
    new Date("1970-01-01"),
    new Date(),
    "adjclose",
    "1d",
  );

  return dailyStockData;
}
```

![A screenshot showing the getData helper function in VS Code.](/assets/stock-market-simulator/get-data-helper.png)

Here are the arguments we pass to `getYahooFinanceData`:

- `symbol` is the stock market symbol. We will use `AAPL` for Apple.
- The two dates define the period. We start in 1970 and finish today so we get all available prices.
- `"adjclose"` selects the adjusted closing price. It accounts for events such as stock splits and dividends, making it useful for estimating investment returns.
- `"1d"` asks for the value at the end of each day.

Note that `getYahooFinanceData` is asynchronous because it fetches data over the Internet. We use the `await` keyword to make sure all the data is received before the rest of the script runs.

<Callout type="info" emoji="💡">
    Under the hood, `getYahooFinanceData` fetches data from a Yahoo Finance API. An API, or *Application Programming Interface*, allows programs to exchange data. We will explore how to find undocumented APIs in the [Web scraping](/data-projects/web-scraping) project.
</Callout>

Now, we can update `main.ts` to import and call our new helper, keeping our code clean.

On line 3, we create the `symbol` variable and assign Apple's stock market symbol, `AAPL`, to it. We pass this variable to `getData`, which expects a `symbol` parameter. Again, we use `await` to make sure we receive all the data before continuing. On line 6, we log the first ten results as a table.

```ts showLineNumbers filename="main.ts"
import getData from "./helpers/getData.ts";

const symbol = "AAPL";
const dailyStockData = await getData(symbol);

console.table(dailyStockData.slice(0, 10));
```

![A screenshot showing main.ts importing and calling the getData helper.](/assets/stock-market-simulator/main-get-data.png)

## Caching

If we were to run `main.ts` right now, the data would be refetched every time the code is executed.

We don’t want to overwhelm Yahoo’s servers with our requests. We must respect their infrastructure. Also, we don’t want to get blacklisted... 🫣 So let's cache the data.

The idea is pretty simple. The first time we fetch the data, we write it to a file. Then, every time the code runs again, if the file exists (which it will), we use it instead of fetching the data again.

So first, create a new folder called `data`, where we will store the cached data.

![A screenshot showing a new data folder in VS Code.](/assets/stock-market-simulator/create-data-folder.png)

Now, we're going to update `getData` to check whether a cached file exists. To do that, we use `Deno.stat()`, which returns information if the file exists. If it doesn't, `catch()` returns `null`. We can then use `if` and `else` branches to read the data from the file if it exists, or fetch fresh data if it doesn't.

```ts showLineNumbers filename="getData.ts"
import { getYahooFinanceData } from "@nshiab/journalism-finance";

export default async function getData(symbol: string) {
  const path = `./data/${symbol}.json`;
  let dailyStockData;

  if (await Deno.stat(path).catch(() => null)) {
    console.log(`=> Cached data found at ${path}. Reading it...`);
    dailyStockData = JSON.parse(await Deno.readTextFile(path));
  } else {
    console.log("=> No cached data found. Fetching it from Yahoo Finance...");
    dailyStockData = await getYahooFinanceData(
      symbol,
      new Date("1970-01-01"),
      new Date(),
      "adjclose",
      "1d",
    );
    console.log(`=> Data fetched. Writing it to ${path} for the next run...`);
    await Deno.writeTextFile(path, JSON.stringify(dailyStockData));
  }

  return dailyStockData;
}
```

<Callout type="info" emoji="💡">
    `catch()` is a way to capture errors triggered by your code. We will explore it in more detail in the [Handling errors with `try` and `catch`](/ninja-moves/try-catch) lesson. Don't worry about it for now. We'll dive into it later.
</Callout>

Here’s what happens when you run this code:

- On line 4, `path` contains the location and name of the cache file. We include `symbol` so each company has its own file and its data isn't overwritten.
- On line 5, `dailyStockData` is a `let` variable because it will receive either cached data or fresh data from Yahoo Finance.
- On line 7, `Deno.stat()` checks whether the file exists.
- If it does, line 8 logs that cached data was found and shows the file path. Line 9 then reads the file and parses its text back into an array of objects.
- Otherwise, line 11 logs that no cached data was found and that fresh data will be fetched from Yahoo Finance. Lines 12–18 then fetch it.
- Once the fresh data has been received, line 19 logs where it will be saved for the next run. Line 20 stringifies the array and writes it to that file.
- Finally, line 23 returns `dailyStockData`, whether it came from the cache or Yahoo Finance.

Now, run and watch `main.ts` with all permissions enabled:

`deno -A --watch --check main.ts`

The first time you run this code, Deno won't find a file named `AAPL.json`. The `if` block on lines 8–9 won't be executed. Instead, lines 11–20 under `else` will run. You'll see the two messages in the terminal, and line 20 will create `AAPL.json` in the `data` folder.

![A screenshot showing stock data being fetched and written to AAPL.json.](/assets/stock-market-simulator/data-fetched-aapl.png)

<Callout type="info" emoji="💡">
    Wondering what `timestamp` means? This huge number is the number of milliseconds since January 1, 1970. This is how JavaScript tracks dates and times behind the scenes. Here, the library gives us the timestamp directly instead of a date, but as we'll see, JavaScript makes it easy to go back and forth between dates and timestamps.
</Callout>

Now, rerun `main.ts` by saving it again (`CMD` + `S` on Mac or `CTRL` + `S` on PC). This time, the condition on line 7 is met because Deno finds `AAPL.json`. Lines 8–9 are executed, while everything under `else` is skipped. We don't need to fetch the data again. We read it from our local file instead. This is faster and doesn't annoy Yahoo's servers with another request.

![A screenshot showing stock data being read from AAPL.json.](/assets/stock-market-simulator/data-cached-aapl.png)

<Callout type="info" emoji="💡">
    Here, we are using caching to avoid pinging Yahoo's servers too many times. But caching is also very commonly used to improve performance. Instead of repeating them every time the script runs, you can cache the results and read them directly on future runs.
</Callout>

## Calculating returns

We now have everything we need to calculate returns!

Let's create another function, `calculateFinalAmount`, in `helpers`. This function will need three parameters:
- The `amount` invested, which must be a `number`
- The `startDate`, which is the `Date` of the investment
- The `dailyStockData` returned by `getYahooFinanceData`, which is an array of objects pairing a `timestamp` with a `value`

```ts showLineNumbers filename="calculateFinalAmount.ts"
export default function calculateFinalAmount(
  amount: number,
  startDate: Date,
  dailyStockData: { timestamp: number; value: number }[],
) {
  console.log("=> Calculating final amount...");

  const filteredDailyStockData = dailyStockData.filter((dailyData) =>
    dailyData.timestamp >= startDate.getTime()
  );

  const initialValue = filteredDailyStockData[0].value;
  const finalValue = filteredDailyStockData[filteredDailyStockData.length - 1]
    .value;
  const rateOfReturn = (finalValue - initialValue) / initialValue;

  return amount + amount * rateOfReturn;
}
```

Here’s what happens when we call this function:

- Line 6 logs when the function is called.
- Lines 8–10 keep only data from the investment date onward.
- Line 12 retrieves the stock's initial value.
- Lines 13–14 retrieve its latest value.
- Line 15 calculates the rate of return, which can be positive or negative.
- Line 17 calculates the final amount: the initial amount plus the amount multiplied by the rate of return.

If we run our code now, nothing will happen. We still need to call our new function in `main.ts`.

First, we import `calculateFinalAmount`. Then, we create the `amount` and `startDate` variables and pass them, along with `dailyStockData`, to the function. Finally, we store its result in a new variable called `finalAmount`.

```ts showLineNumbers filename="main.ts" {2, 5-6, 10, 12}
import getData from "./helpers/getData.ts";
import calculateFinalAmount from "./helpers/calculateFinalAmount.ts";

const symbol = "AAPL";
const amount = 1000;
const startDate = new Date("2020-01-01");

const dailyStockData = await getData(symbol);

const finalAmount = calculateFinalAmount(amount, startDate, dailyStockData);

console.log(finalAmount);
```

And here's the result! It works! You would have approximately $4,639 today (as of September 2026) if you had invested $1,000 in Apple in January 2020.

![A screenshot showing the final amount invested.](/assets/stock-market-simulator/final-amount.png)

## Displaying the result

Let's create a function to display the result more clearly.

In `helpers`, create a function called `logResult`.

To make the message easier to read, we format `startDate` with `.toLocaleDateString("en-US")`. `"en-US"` is what we call a locale. It specifies that the date should be formatted in English for the United States, but you can pass any locale you want, such as `"fr-CA"` for French in Canada. We also round `finalAmount` with `Math.round()`.

```ts showLineNumbers filename="logResult.ts"
export default function logResult(
  amount: number,
  symbol: string,
  startDate: Date,
  finalAmount: number,
) {
  const formattedDate = startDate.toLocaleDateString("en-US");
  const roundedAmount = Math.round(finalAmount);

  console.log(
    `\nIf you had invested $${amount} in ${symbol} on ${formattedDate}, you would have $${roundedAmount} today.\n`,
  );
}
```

We can now use this function in `main.ts`.

```ts showLineNumbers filename="main.ts" {3, 13}
import getData from "./helpers/getData.ts";
import calculateFinalAmount from "./helpers/calculateFinalAmount.ts";
import logResult from "./helpers/logResult.ts";

const symbol = "AAPL";
const amount = 1000;
const startDate = new Date("2020-01-01");

const dailyStockData = await getData(symbol);

const finalAmount = calculateFinalAmount(amount, startDate, dailyStockData);

logResult(amount, symbol, startDate, finalAmount);
```

## Wait a minute...

Everything works fine with a `startDate` of January 2020... But what would happen if the start date was in 1970, before Apple was publicly traded?

That's impossible! Our code should warn the user.

Update `startDate` to `"1950-01-01"` to test it out... It's returning an amount, but it should be throwing an error! 😱

![A VS Code screenshot showing an impossible investment result for a date before Apple was publicly traded.](/assets/stock-market-simulator/impossible-result.png)

Let's squash this bug! 🐛

We can update `calculateFinalAmount`, which already receives both `startDate` and `dailyStockData`. The lines we're adding below compare the investment date with the first available price. If the investment date is earlier, the helper throws an error with a message.

```ts showLineNumbers filename="calculateFinalAmount.ts" {8-12}
export default function calculateFinalAmount(
  amount: number,
  startDate: Date,
  dailyStockData: { timestamp: number; value: number }[],
) {
  console.log("=> Calculating final amount...");

  if (startDate.getTime() < dailyStockData[0].timestamp) {
    throw new Error(
      "The company was not public at that time. Please choose a later date.",
    );
  }

  const filteredDailyStockData = dailyStockData.filter((dailyData) =>
    dailyData.timestamp >= startDate.getTime()
  );

  const initialValue = filteredDailyStockData[0].value;
  const finalValue = filteredDailyStockData[filteredDailyStockData.length - 1]
    .value;
  const rateOfReturn = (finalValue - initialValue) / initialValue;

  return amount + amount * rateOfReturn;
}
```

![A screenshot showing an error being thrown from calculateFinalAmount.](/assets/stock-market-simulator/error.png)

<Callout type="info" emoji="💡">
    Throwing an error stops the script and (hopefully) provides a useful message. The error also shows where it originated. In the screenshot above, `calculateFinalAmount.ts:9:11` means line 9, character 11 of that file. In VS Code, `CMD` + click this reference to jump directly to the error, which is very handy for debugging.
</Callout>

That's better. We won't return impossible results now! You can safely play with different `startDate` values.

But are we completely safe? What happens if you provide a date in the future? 🤔 Try to find a way to throw a different error when that happens. Here's a hint: `Date.now()` gives you the current date and time as a number of milliseconds.

# Mathématiques pour les journalistes

Mes collègues me posent souvent des questions sur les pourcentages, les moyennes, les médianes et d’autres calculs souvent utilisés dans les salles de rédaction.

J’ai donc créé une page interactive pour expliquer ces notions. Je vous invite à découvrir le [carnet Observable](https://observablehq.com/@nshiab/math-for-journalists).

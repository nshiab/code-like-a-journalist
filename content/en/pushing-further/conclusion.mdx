# Conclusion

<NoticeIntro />

You now have the tools to build a complete TypeScript project! 🎉 You can organize your code with functions and classes, save and read files, fetch data from the web, install libraries, and define Deno tasks for commands you use often.

## Put it into practice

Try the [Stock market simulator 📈](/data-projects/stock-market-simulator). You'll fetch historical prices, save data locally so you can reuse it, and organize your code into functions and files. Then you'll calculate how an investment would have changed over time.

This project builds on chapters 1 and 2. If you would like a smaller exercise first, start with the [Savings calculator 💸](/data-projects/saving-account-calculator), which uses the fundamentals from chapter 1.

As you work, pay attention to where each part belongs: fetching data, preparing it, calculating results, and displaying them. Giving each function a clear job will make the code easier to understand and update.

Both projects are in **Data projects** at the end of the sidebar, ready whenever you want to practise.

## What's next?

In [Data analysis with SDA](/simple-data-analysis/tabular-data), you'll use the Simple Data Analysis library to work with tables, geographic data, and visualizations. You'll build on your TypeScript skills to answer questions with larger datasets.

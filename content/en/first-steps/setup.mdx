# Setup

First, let's install everything we need.

You might need administrator rights on your machine. If you are on your work computer and don't have them, ask your IT department.

## Code editor

Code is just text. You can write your code in any text editor, but it's more convenient to use a code editor that comes with many useful features.

You have many free and interesting options, but the most popular is [Visual Studio Code](https://code.visualstudio.com/), and it's the one we will use. It's an [open-source project](https://github.com/microsoft/vscode) maintained by Microsoft.

Download it from the [website](https://code.visualstudio.com/) and install it.

Once installed, open it. It should look like this. It's okay if you have different tabs open.  

![A screenshot of the code editor Visual Studio Code.](/assets/first-steps/setup/vscode.png)

Personally, I find the interface to be too small (👴 maybe it's a sign I'm getting older), and I always adjust it to be a bit bigger when I set up a new machine. To do so, click on the `View => Appearance => Zoom In` menu.

![A screenshot of the View menu in VS Code.](/assets/first-steps/setup/vscode-zoom.png)

Let's adjust a few useful settings.

To open Settings on Mac, click `Code => Preferences => Settings`, as shown below. On Windows, use `File => Preferences => Settings`. You can also press `Command` + `,` on Mac or `Control` + `,` on Windows.

![VS Code on Mac with the Code and Preferences menus open and an arrow pointing to Settings.](/assets/first-steps/setup/vscode-open-settings.png)

In the Settings search box, type `format`, then check `Editor: Format On Save`.

Just below it, set `Editor: Default Formatter` to `JavaScript and TypeScript Language Features`.

With these settings, each time you save, VS Code will tidy the spacing and indentation of your code to make it easier to read.

You don't need to click a Save button for your settings. Changes take effect as soon as you make them.

![VS Code Settings with arrows pointing to the format search, the enabled Format On Save checkbox, and JavaScript and TypeScript Language Features selected as the default formatter.](/assets/first-steps/setup/vscode-format-on-save.png)

While you're in Settings, search for `wrap` and set `Editor: Word Wrap` to `on`. Long lines will automatically continue on the next screen line, so you won't need to scroll sideways to read them.

![VS Code Settings with arrows pointing to the search box and Editor: Word Wrap set to on.](/assets/first-steps/setup/vscode-word-wrap.png)

Click the X in the top-right corner of the Settings window to close it.

![VS Code Settings with an arrow pointing to the X in the top-right corner to close the window.](/assets/first-steps/setup/vscode-close-settings.png)

## Runtime

To execute our TypeScript code, we need a runtime. We will use [Node.js](https://nodejs.org/), a free runtime that has been around since 2009. I think it's one of the most impressive open-source projects: thousands of people have contributed over the years to make it faster, more reliable, and more secure.

For this course, we will install the latest LTS version. LTS stands for long-term support, which means this version will be maintained for a long time.

Visit the [Node.js download page](https://nodejs.org/en/download), select the latest LTS version and your operating system, and follow the installation instructions.

It's okay if the LTS version available to you isn't exactly the same as the one in my screenshot.

![The Node.js download page, with arrows pointing to the LTS version and the macOS installer.](/assets/first-steps/setup/node-download.png)

After installing Node.js, fully quit and reopen VS Code so it can find the new installation. On Mac, press `Command` + `Q`; on Windows, use `File => Exit`.

To check that Node.js has been properly installed, we're going to check its version in the terminal.

To open the terminal in VS Code, click on the `View` menu and then on `Terminal`, or press `Command` + `J` on Mac or `Control` + `J` on Windows.

![VS Code with the View menu open and arrows pointing to View and the Terminal menu item.](/assets/first-steps/setup/vscode-terminal.png)

To check the installation, type the following command in the terminal and press Enter:

```sh
node --version
```

This command should display the Node.js version you just installed.

![The VS Code terminal displaying the installed Node.js version after running node --version.](/assets/first-steps/setup/node-version.png)

## Let's run a script

Now that setup is done, it's time to run some code! By the way, files containing code are often called scripts. 🤓

First, decide where to store your code files. Create a new, empty folder somewhere handy on your computer. Then, in VS Code, click on the Explorer tab in the top-left corner, click the `Open Folder` button, and select that folder.

![VS Code with arrows pointing to the Explorer tab and the Open Folder button.](/assets/first-steps/setup/vscode-open-folder.png)

For this lesson, I called my new folder `test`. I can now see its name in the Explorer on the left, which shows that this is the folder I have open.

In my terminal, I can also see `test`. This means commands I run there will run from this folder too.

By the way, if you still have the `Welcome` tab open, you can now close it by clicking the X next to its title.

![VS Code with arrows pointing to the test folder in Explorer, test in the terminal prompt, and the Welcome tab's close button.](/assets/first-steps/setup/vscode-project-folder.png)

In the Explorer on the left, right-click inside your folder and choose `New File`. Name the file `main.ts` and press Enter. The `.ts` extension means this file contains TypeScript code. We'll use this file in the next lessons.

![VS Code with the Explorer context menu open and an arrow pointing to New File.](/assets/first-steps/setup/vscode-new-file.png)

Click on `main.ts` to open it. A new tab will appear with the file's content. For now, it's empty. In it, type this line:

```ts showLineNumbers filename="main.ts"
console.log("This is going to be fun!");
```

Next to `main.ts` in the tab title, you'll see a white dot. This means the file has been modified but hasn't been saved yet.

![VS Code showing main.ts with a line of code and a white dot in the tab title indicating unsaved changes.](/assets/first-steps/setup/vscode-unsaved-file.png)

To save the file, make sure you're in it and press `Command` + `S` on Mac or `Control` + `S` on Windows. The white dot disappears and is replaced by an X when you save.

![VS Code showing the saved main.ts file with an X in place of the white dot in the tab title.](/assets/first-steps/setup/vscode-saved-file.png)

Now we have code in `main.ts`. This code is very simple: it will log `This is going to be fun!` in the terminal.

To run the code, we need the terminal. If you closed it or it isn't open, click on the `View` menu and then on `Terminal`, or press `Command` + `J` on Mac or `Control` + `J` on Windows.

Running the code is very simple. First, type `node` to indicate that you want to use the Node.js runtime, then the name of the file you want Node.js to run: `main.ts`.

Type this command in the terminal and press Enter:

```sh
node main.ts
```

You should now see `This is going to be fun!` in the terminal. Congrats! You just ran your first line of TypeScript! 🎉

![VS Code showing node main.ts running in the terminal and displaying This is going to be fun!.](/assets/first-steps/setup/node-run-main.png)

## Automatically rerun a script when you save

When you're working on a project, you usually want to run your script more than once. As you write the code, seeing the result helps you check that you're heading in the right direction. That's why we often code in watch mode.

To run your script in watch mode, use this command in the terminal:

```sh
node --watch main.ts
```

The `--watch` option tells Node.js to keep watching the file. Each time you save a change, it automatically clears the terminal and runs the code again.

When you run this command, you'll see that the code runs again. A new blue line also appears in the terminal, saying that Node.js is waiting for file changes before restarting.

![VS Code showing node --watch main.ts and a blue message saying it is waiting for file changes before restarting.](/assets/first-steps/setup/node-watch-main.png)

Let's try it! Replace the text in `main.ts` with a different message:

```ts showLineNumbers filename="main.ts"
console.log("Hello again!");
```

Save the file (`Command` + `S` on Mac or `Control` + `S` on Windows).

As soon as you save, the terminal clears and Node.js tells you it detected a change in your script and restarted it. You can see `Hello again!` in the terminal, followed by a message saying that Node.js is still watching the file in case you change it again.

![VS Code showing Hello again! in main.ts and terminal messages confirming the change was detected, the script restarted, and Node.js is waiting for more changes.](/assets/first-steps/setup/node-watch-restart.png)

Now you know how to create a file, write TypeScript code, run it in the terminal, and use watch mode as you work. We'll use this simple setup in the lessons ahead. Congrats! 🎉

To stop watching, click in the terminal and press `Control` + `C` on Mac or Windows. For the next lessons, you can keep using this folder and replace the code in `main.ts`.

## About AI

You may have noticed that we haven’t installed any AI-powered tools, such as [GitHub Copilot](https://github.com/features/copilot).

These tools are increasingly popular for coding tasks and can significantly boost productivity. However, they are not without flaws. They can introduce errors and bugs.

For experienced coders, this isn’t a big issue. When you know what you’re doing, you can easily review and refine the AI's output.

For beginners, though, it’s better to hold off. Master the basics first, and once you have a solid foundation, you’ll be in a much better position to benefit from these tools.

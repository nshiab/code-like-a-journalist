## Configuration

Créez un nouveau dossier vide sur votre ordinateur, ouvrez-le avec VS Code et créez-y un fichier nommé `main.ts`.

Tapez ce code dans `main.ts` et enregistrez le fichier :

```ts showLineNumbers filename="main.ts"
console.log("Hello!");
```

Ouvrez le terminal (`Command` + `J` sur Mac ou `Control` + `J` sur Windows) et exécutez cette commande :

```sh
node --watch main.ts
```

Cette commande exécute notre code et le relance automatiquement chaque fois que nous enregistrons une modification, pour voir les résultats au fur et à mesure que nous travaillons.

## Instructions conditionnelles

Pour écrire des conditions, nous utilisons les instructions conditionnelles `if`, `else if`, et `else`.

La première condition doit toujours être testée avec `if`. La condition doit être placée entre `()`. Si la condition est remplie, l'ordinateur exécutera le code à l'intérieur des `{}` qui suivent.

Par exemple, le code ci-dessous affiche `I am older than you!` dans le terminal uniquement si `myAge` est supérieur à `yourAge`.

```ts showLineNumbers filename="main.ts"
const myAge = 36;
const yourAge = 25;

if (myAge > yourAge) {
  console.log("I am older than you!");
}
```

Comme `36` est supérieur à `25`, la condition est remplie et le message apparaît dans le terminal.

![VS Code montrant myAge supérieur à yourAge et I am older than you! dans le terminal.](/assets/first-steps/conditions/if-age-true.png)

Remplacez maintenant `yourAge` par `55` et enregistrez le fichier :

```ts showLineNumbers filename="main.ts" {2}
const myAge = 36;
const yourAge = 55;

if (myAge > yourAge) {
  console.log("I am older than you!");
}
```

Maintenant, `myAge` n’est pas supérieur à `yourAge` : le `console.log` n’est donc pas exécuté et aucun message n’est affiché dans le terminal.

![VS Code montrant yourAge défini à 55 et aucun message affiché dans le terminal.](/assets/first-steps/conditions/if-age-false.png)

Si nous voulons tester plus d'une condition, nous utilisons `else if` avec une condition entre `()` suivie par du code à exécuter à l'intérieur des `{}`.

Dans l'exemple ci-dessous, nous voulons aussi afficher `You are older than me!` si `myAge` est inférieur à `yourAge`.

```ts showLineNumbers filename="main.ts" {6-8}
const myAge = 36;
const yourAge = 55;

if (myAge > yourAge) {
  console.log("I am older than you!");
} else if (myAge < yourAge) {
  console.log("You are older than me!");
}
```

Si vous exécutez ce code, vous verrez maintenant `You are older than me!` dans le terminal.

![VS Code montrant la condition else if affichant You are older than me! dans le terminal.](/assets/first-steps/conditions/else-if-age.png)

Mais que se passe-t-il si `myAge` et `yourAge` sont exactement identiques ? Définissez les deux âges à `36` et enregistrez :

```ts showLineNumbers filename="main.ts" {2}
const myAge = 36;
const yourAge = 36;

if (myAge > yourAge) {
  console.log("I am older than you!");
} else if (myAge < yourAge) {
  console.log("You are older than me!");
}
```

De nouveau, rien ne s’affiche : nos conditions couvrent uniquement les âges supérieurs ou inférieurs, pas les âges égaux.

![VS Code montrant les deux âges définis à 36 et aucun message affiché, car aucune des conditions n’est remplie.](/assets/first-steps/conditions/else-if-age-equal.png)

Si nous voulons exécuter du code lorsque aucune des conditions n'est remplie, nous utilisons `else`. Puisque `else` ne teste aucune condition, nous n'avons pas besoin de `()`, mais nous devons fournir le code à exécuter à l'intérieur des `{}`. Bien que terminer avec un `else` ne soit pas obligatoire, cela aide souvent à éviter des bogues.

Par exemple, dans le code ci-dessous, si aucune des conditions n'est remplie, cela signifie que nous avons le même âge. Nous utilisons donc `else` pour afficher `We are the same age!` dans le terminal.

```ts showLineNumbers filename="main.ts" {8-10}
const myAge = 36;
const yourAge = 36;

if (myAge > yourAge) {
  console.log("I am older than you!");
} else if (myAge < yourAge) {
  console.log("You are older than me!");
} else {
  console.log("We are the same age!");
}
```

![VS Code montrant les deux âges définis à 36 et le bloc else affichant We are the same age! dans le terminal.](/assets/first-steps/conditions/conditions-age.png)

<Callout type="info" emoji="💡">
  Avez-vous remarqué l'absence de `;` à la ligne 10 ? C'est parce que lorsque vous utilisez `{}`, vous créez un **bloc de code**. L'accolade fermante indique déjà à l'ordinateur que c'est la fin du bloc, donc un point-virgule supplémentaire à la fin n'est pas nécessaire.
</Callout>

## Opérateurs de comparaison

Lorsque vous utilisez `if` et `else if`, la condition à l'intérieur des `()` doit toujours donner une valeur booléenne (`true` ou `false`).

L'exemple précédent fonctionne parce que nous avons utilisé les opérateurs de comparaison `>` et `<`, qui renvoient une valeur booléenne.

Voici les principaux opérateurs de comparaison que vous utiliserez au quotidien :
- `>` : supérieur à
- `>=` : supérieur ou égal à
- `<` : inférieur à
- `<=` : inférieur ou égal à
- `===` : égal à
- `!==` : différent de

<Callout type="info" emoji="💡">
  Vous pourriez voir des exemples sur le web avec `==` et `!=`. Ces opérateurs peuvent convertir automatiquement les valeurs avant de les comparer, ce qui peut produire des résultats inattendus. Il est préférable d'utiliser `===` et `!==`, qui comparent sans convertir les types.
</Callout>

Et voici les opérateurs en action. Nous stockons les résultats dans des variables et les affichons :

```ts showLineNumbers filename="main.ts"
// Modifiez les âges pour tester les différents opérateurs.
// Ne vous préoccupez pas de `: number` pour le moment.
const myAge: number = 36;
const yourAge: number = 25;

const greater = myAge > yourAge;
console.log("greater =>", greater);

const greaterOrEqual = myAge >= yourAge;
console.log("greaterOrEqual =>", greaterOrEqual);

const younger = myAge < yourAge;
console.log("younger =>", younger);

const youngerOrEqual = myAge <= yourAge;
console.log("youngerOrEqual =>", youngerOrEqual);

const sameAge = myAge === yourAge;
console.log("sameAge =>", sameAge);

const differentAge = myAge !== yourAge;
console.log("differentAge =>", differentAge);
```

![VS Code montrant les opérateurs de comparaison et leurs résultats booléens dans le terminal.](/assets/first-steps/conditions/operators.png)

## Opérateurs logiques

Parfois, vous voulez vérifier plusieurs conditions dans une seule instruction. C'est là que les opérateurs logiques `&&` et `||` sont utiles.

- `&&` signifie **ET**
- `||` signifie **OU**

Par exemple, disons que nous avons besoin d'un algorithme pour vérifier si vous avez l'âge légal pour consommer une boisson dans un bar au Québec (au moins 18 ans) ou en Ontario (au moins 19 ans). 🥂🇨🇦

Sans opérateurs logiques, cela pourrait ressembler à ceci, avec des conditions imbriquées. Cela fonctionne, mais les conditions imbriquées peuvent être difficiles à lire et à déboguer.

```ts showLineNumbers filename="main.ts"
// Modifiez l'âge et la province pour tester les conditions.
// Ne vous préoccupez pas de `: number` et `: string` pour le moment.
const myAge: number = 18;
const myProvince: string = "Quebec";

if (myProvince === "Quebec") {
  // Après avoir vérifié la province, nous vérifions aussi l'âge.
  if (myAge >= 18) {
    console.log("You are allowed! 🍺");
  } else {
    console.log("You are not allowed! 🚫");
  }
} else if (myProvince === "Ontario") {
  if (myAge >= 19) {
    console.log("You are allowed! 🍺");
  } else {
    console.log("You are not allowed! 🚫");
  }
} else {
  console.log("I don't know this province! 🤷");
}
```

![VS Code montrant des conditions imbriquées autorisant une personne de 18 ans au Québec et affichant You are allowed! 🍺.](/assets/first-steps/conditions/logical-nested.png)

Voici le même code avec l'opérateur logique `&&` pour s'assurer que `myAge` **ET** `myProvince` respectent des conditions spécifiques. Cette approche est plus simple à comprendre et plus facile à déboguer !

```ts showLineNumbers filename="main.ts"
// Modifiez l'âge et la province pour tester les conditions.
// Ne vous préoccupez pas de `: number` et `: string` pour le moment.
const myAge: number = 18;
const myProvince: string = "Quebec";

if (myProvince === "Quebec" && myAge >= 18) {
  // Québec ET au moins 18 ans.
  console.log("You are allowed! 🍺");
} else if (myProvince === "Ontario" && myAge >= 19) {
  // Ontario ET au moins 19 ans.
  console.log("You are allowed! 🍺");
} else if (myProvince !== "Quebec" && myProvince !== "Ontario") {
  // La province n'est ni le Québec ni l'Ontario.
  console.log("I don't know this province! 🤷");
} else {
  console.log("You are not allowed! 🚫");
}
```

Nous pourrions aussi écrire le même algorithme avec un mélange de `&&` et de `||`. Nous pouvons également utiliser des variables pour simplifier le code.

```ts showLineNumbers filename="main.ts"
// Modifiez l'âge et la province pour tester les conditions.
// Ne vous préoccupez pas de `: number` et `: string` pour le moment.
const myAge: number = 18;
const myProvince: string = "Quebec";

// Stockez chaque condition combinée sous forme de true ou false.
const isAllowedInQuebec = myProvince === "Quebec" && myAge >= 18;
const isAllowedInOntario = myProvince === "Ontario" && myAge >= 19;
const unknownProvince = myProvince !== "Quebec" && myProvince !== "Ontario";

if (isAllowedInQuebec || isAllowedInOntario) {
  console.log("You are allowed! 🍺");
} else if (unknownProvince) {
  console.log("I don't know this province! 🤷");
} else {
  console.log("You are not allowed! 🚫");
}
```

Comme en français, il existe plusieurs façons d’exprimer la même logique en code. Gardez votre code facile à lire et à comprendre pour pouvoir le reprendre facilement, même plusieurs mois plus tard, et permettre à vos collègues de comprendre et de réviser rapidement votre travail.

## Opérateur conditionnel

Il existe une autre façon d'écrire des instructions conditionnelles simples en utilisant la syntaxe `condition ? valueWhenTrue : valueWhenFalse`. Cette syntaxe est appelée **opérateur conditionnel** (également connu sous le nom d'**opérateur ternaire**).

C'est idéal pour des conditions simples, vous permettant de remplacer les instructions `if` et `else` par une seule ligne.

Voici une autre variation de notre algorithme en utilisant cette syntaxe.

```ts showLineNumbers filename="main.ts"
// Modifiez l'âge et la province pour tester les conditions.
// Ne vous préoccupez pas de `: number` et `: string` pour le moment.
const myAge: number = 18;
const myProvince: string = "Quebec";

const quebecMessage = myAge >= 18
  ? "You are allowed! 🍺"
  : "You are not allowed! 🚫";

const ontarioMessage = myAge >= 19
  ? "You are allowed! 🍺"
  : "You are not allowed! 🚫";

if (myProvince === "Quebec") {
  console.log(quebecMessage);
} else if (myProvince === "Ontario") {
  console.log(ontarioMessage);
} else {
  console.log("I don't know this province! 🤷");
}
```

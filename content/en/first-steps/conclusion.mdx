# Conclusion

<NoticeIntro />

You’ve reached the end of TypeScript fundamentals! 🎉 You can now create variables, work with different data types, organize values in arrays and objects, make decisions with conditions, and repeat operations with loops. You also know how to run your code with Deno and use VS Code to spot errors.

## Put it into practice

Try the [Savings calculator 💸](/data-projects/saving-account-calculator). You'll combine the concepts from this chapter to calculate how a balance changes over time, then experiment with different interest rates. The project walks you through the calculations as you go.

Once it works, change the starting balance or the number of years. Before running the code, try to predict how the result will change. If something surprises you, use `console.log` to inspect the values along the way.

You can find this project in **Data projects** at the end of the sidebar. You don't need to finish the rest of the course before trying it.

## What's next?

In [Working with TypeScript](/pushing-further/functions), you'll learn to organize your code with functions and classes, read and write files, fetch data, use libraries, and run tasks. These tools will let you build projects that do more than work with values you typed yourself.

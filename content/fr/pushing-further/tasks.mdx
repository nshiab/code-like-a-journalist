# Exécuter des tâches

Les tâches permettent d'éviter de retaper de longues commandes dans le terminal. Elles sont très pratiques et largement utilisées. Avec npm, on les appelle des **scripts** et on les définit dans `package.json`.

Notez que je suppose que vous avez terminé la [leçon d'installation](/first-steps/setup) avant de vous lancer dans celle-ci.

<NoticeIntro lang="fr" />

## Configuration

Créez un nouveau dossier vide sur votre ordinateur, ouvrez-le avec VS Code et créez-y un fichier nommé `main.ts`.

Tapez ce code dans `main.ts` et enregistrez le fichier :

```ts showLineNumbers filename="main.ts"
console.log("Hello!");
```

Ouvrez le terminal (`Command` + `J` sur Mac ou `Control` + `J` sur Windows) et exécutez cette commande :

```sh
node --watch main.ts
```

Cette commande exécute notre code et le relance automatiquement chaque fois que nous enregistrons une modification, pour voir les résultats au fur et à mesure que nous travaillons.

## Créer des scripts npm

Remplacez le contenu de `main.ts` par le code suivant et enregistrez le fichier. Ce script provient de la leçon [Récupérer des données](/pushing-further/fetch). Il récupère un fichier JSON depuis GitHub, le convertit et l'affiche dans le terminal.

```ts showLineNumbers filename="main.ts"
const response = await fetch(
  "https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.json",
);

const data = await response.json();

console.log(data);
```

Vous avez déjà utilisé `node --watch main.ts` pour exécuter et surveiller votre code. Donnons un nom plus court à cette commande !

Si votre dossier ne contient pas de `package.json`, créez-en un en exécutant `npm init -y` dans le terminal. Arrêtez d'abord toute surveillance avec `CTRL` + `C`. `npm` est fourni avec Node.js : vous n'avez pas besoin de l'installer séparément.

Ouvrez `package.json`. Ajoutez ou modifiez son objet **scripts** pour inclure ces entrées et définissez `type` sur `module`. Le fichier devrait ressembler à ceci, en conservant les dépendances et les autres champs existants :

```json showLineNumbers filename="package.json"
{
  "type": "module",
  "scripts": {
    "watch": "node --watch main.ts",
    "once": "node main.ts"
  }
}
```

Le paramètre `type` indique à Node.js que notre projet utilise `import` et `export`. N'oubliez pas les virgules entre les entrées voisines, puis enregistrez le fichier ! 🙃

Exécutez maintenant :

```sh
npm run watch
```

npm trouve `watch` dans `scripts` et exécute `node --watch main.ts`. Votre code est relancé chaque fois que vous l'enregistrez, comme auparavant.

Et si vous voulez l'exécuter une seule fois ? Arrêtez la surveillance avec `CTRL` + `C`, puis exécutez :

```sh
npm run once
```

Votre code s'exécute une seule fois, puis s'arrête. Si vous changez la commande définie dans `once` plus tard, vous utiliserez toujours le même raccourci : `npm run once`.

    Vous pouvez définir autant de scripts que nécessaire. Lancez `npm run` sans nom de script pour afficher ceux qui sont disponibles.

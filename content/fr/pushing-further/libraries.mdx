# Utiliser des bibliothèques

Des millions de personnes à travers le monde travaillent avec JavaScript et TypeScript. L'une des raisons de leur popularité est l'immense écosystème de bibliothèques. De nombreux développeurs partagent leur code publiquement, ce qui permet à tout le monde de l'utiliser gratuitement.

Dans les prochaines leçons, nous utiliserons des bibliothèques en code ouvert pour analyser d'énormes ensembles de données et créer de superbes visualisations.

Une note sur le vocabulaire : les *bibliothèques* sont aussi souvent appelées *libraries*, *packages* ou *modules*.

Je suppose que vous avez terminé le chapitre 1 et toutes les leçons précédentes du chapitre 2 avant de vous lancer dans celle-ci. Assurez-vous notamment d’avoir suivi la [leçon d’installation](/first-steps/setup).

## Configuration

Créez un nouveau dossier vide sur votre ordinateur, ouvrez-le avec VS Code et créez-y un fichier nommé `main.ts`.

Tapez ce code dans `main.ts` et enregistrez le fichier :

```ts showLineNumbers filename="main.ts"
console.log("Hello!");
```

Ouvrez le terminal (`Command` + `J` sur Mac ou `Control` + `J` sur Windows) et exécutez cette commande :

```sh
node --watch main.ts
```

Cette commande exécute notre code et le relance automatiquement chaque fois que nous enregistrons une modification, pour voir les résultats au fur et à mesure que nous travaillons.

![VS Code montrant console.log("Hello!") dans main.ts et Hello! dans le terminal exécutant node --watch main.ts.](/assets/first-steps/variables/run.png)

## Le registre npm

Les bibliothèques sont publiées sur des registres publics. Dans ce cours, nous les installerons depuis [npm](https://www.npmjs.com/), le registre utilisé par la commande npm fournie avec Node.js. Les pages des paquets présentent la documentation, les responsables, les versions et les téléchargements pour vous aider à choisir une bibliothèque.

Prenons un exemple et recherchons `d3`, une bibliothèque bien connue pour la visualisation de données que nous utiliserons fréquemment.

Allez sur [npmjs.com](https://www.npmjs.com/) et recherchez `d3`.

![Une capture d'écran montrant les résultats de NPM pour d3.](/assets/pushing-further/libraries/d3-npm.png)

Sélectionnez le premier résultat : `d3` avec la description **"Data-Driven Documents"** par Mike Bostock.

Voici [le lien direct](https://www.npmjs.com/package/d3), au cas où.

![Une capture d'écran montrant la description de d3 sur NPM.](/assets/pushing-further/libraries/d3-description.png)

Cette page fournit de nombreuses informations utiles :
- Dans la section principale, on voit une courte description et des liens vers la documentation, des exemples, et plus encore.
- Sur la droite, il y a un lien vers la page GitHub et le site officiel de la bibliothèque.
- On peut voir le nombre de téléchargements hebdomadaires, indiquant la popularité de la bibliothèque.
- La liste des responsables inclut **Mike Bostock** et **Philippe Rivière**, deux experts bien connus en visualisation de données.

Ces détails (ainsi que ceux sur la page GitHub) nous aident à déterminer si une bibliothèque est fiable. Soyez toujours prudent avant d'exécuter du code inconnu ! 🦠

## Installer une bibliothèque

Installer une bibliothèque depuis npm est très simple. Lorsque vous avez installé Node.js, vous avez aussi installé npm. Pour installer `d3`, vous n’avez qu’une commande à exécuter dans votre terminal. Avant de la lancer, n’oubliez pas d’arrêter la surveillance de votre code (`Control` + `C`).

```sh
npm install d3
```

Une fois la commande terminée, vous verrez quelques nouveautés dans votre projet. Dans l’exemple ci-dessous, le terminal indique que 38 paquets ont été installés : D3 est composé d’autres modules, que npm installe aussi.

Dans le panneau Explorateur, en haut à gauche, vous verrez un nouveau dossier `node_modules`. C’est là que npm place le code de D3 et de ses dépendances sur votre ordinateur pour ce projet.

Vous verrez aussi `package.json`, qui contient la liste des dépendances de votre projet. Ouvrez-le : vous y trouverez `d3`. Le fichier `package-lock.json` conserve des informations supplémentaires sur les paquets et les versions exactes installées. Vous n’avez pas besoin de vous en préoccuper pour le moment.

![VS Code montre npm install d3 ajoutant 38 paquets, le dossier node_modules et d3 dans package.json.](/assets/pushing-further/libraries/npm-install-d3.png)

<Callout type="info" emoji="💡">
    Vous n’avez pas besoin de modifier `node_modules` ou `package-lock.json`, et très souvent, vous n’aurez pas non plus à toucher à `package.json`. Vous pouvez laisser Node.js et npm les gérer. C’est simplement utile de savoir ce qu’ils contiennent.
</Callout>

## Utiliser une bibliothèque

Reprenons le [fichier CSV des températures de Montréal](https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.csv) de la leçon [Récupérer des données](/pushing-further/fetch).

Si vous récupérez ces données, vous remarquerez que c'est juste du texte. CSV signifie **Comma-Separated Values** (valeurs séparées par des virgules) et vous ne pouvez pas travailler avec directement. Il serait bien mieux de le convertir en une liste d'objets.

Modifiez `main.ts` avec le code ci-dessous, puis exécutez la commande suivante : `node --watch main.ts`

```ts showLineNumbers filename="main.ts"
// @ts-ignore
const response = await fetch(
  "https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.csv",
);

// @ts-ignore
const data = await response.text();

console.log(data);
```

![VS Code affiche les données CSV de température récupérées sous forme de texte dans le terminal.](/assets/pushing-further/libraries/csv-text-output.png)

<Callout type="info" emoji="💡">
    Vous vous demandez peut-être ce que signifie `// @ts-ignore`. Ce commentaire indique à VS Code d’ignorer les erreurs de type sur la ligne suivante. Je l’ai ajouté parce qu’appeler `fetch` avec `await` de cette façon demande une configuration supplémentaire pour TypeScript. Je ne veux pas vous embêter avec cela pour le moment : je veux simplement que vous vous concentriez sur `fetch`.
</Callout>

C'est notre jour de chance : la fonction `csvParse` de `d3` convertit les données CSV en une liste d'objets !

Pour importer une fonction de la bibliothèque D3, nous utilisons `import { csvParse } from "d3"`. Le nom de la fonction se place entre accolades, et `"d3"` est le nom du paquet que nous avons installé. Mettons à jour notre code pour l’utiliser.

```ts showLineNumbers filename="main.ts" {1, 8, 10}
import { csvParse } from "d3";

const response = await fetch(
  "https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.csv",
);

const data = await response.text();
const arrayOfObjects = csvParse(data);

console.log(arrayOfObjects);
```
![VS Code signale une erreur TypeScript sur l’import de d3 parce que ses définitions de types sont manquantes, avec les données CSV analysées dans le terminal.](/assets/pushing-further/libraries/d3-missing-types.png)

Comme le montre la capture ci-dessus, notre code fonctionne, mais nous avons une erreur TypeScript. Survolez `"d3"` à la ligne 1 pour voir les détails : les définitions de types de D3 sont manquantes. L’infobulle nous indique aussi comment les installer. Arrêtez la surveillance de votre code (`Control` + `C`), puis exécutez cette commande dans le terminal :

```sh
npm install @types/d3
```

L’erreur a maintenant disparu, et TypeScript connaît les types des fonctions de D3. Relancez `node --watch main.ts`. Comme vous pouvez le voir dans le terminal ci-dessous, nos données CSV ont été converties en une liste d’objets, qui sera beaucoup plus facile à utiliser avec TypeScript !

![VS Code montre l’import de D3 sans erreurs et les données CSV converties en une liste d’objets dans le terminal.](/assets/pushing-further/libraries/d3-parsed-output.png)

<Callout type="info" emoji="💡">
    Dans la [leçon sur les fonctions](/pushing-further/functions), nous avons vu que nous pouvons importer des fonctions avec la syntaxe `import myFunction from "./myFunction.ts"`. Ici, c'est un peu différent, car `d3` exporte plusieurs fonctions, et nous choisissons uniquement celle(s) que nous voulons. Pour cela, nous utilisons des accolades avec cette syntaxe : `import { myFunctionA, myFunctionB } from "./allMyFunctions.ts"`.
</Callout>

Félicitations ! Vous venez d’installer `d3` depuis NPM et d’utiliser l’une de ses fonctions ! 💃🕺

## Une autre bibliothèque : csv-parse

Plusieurs bibliothèques peuvent souvent résoudre le même problème. Essayons [`csv-parse`](https://www.npmjs.com/package/csv-parse), une bibliothèque spécialisée dans la lecture des fichiers CSV. Sa documentation présente les interfaces disponibles, les options, des exemples et un lien vers le code source.

Arrêtez le script avec `CTRL` + `C`, puis installez-la :

```sh
npm install csv-parse
```

Si vous consultez votre `package.json`, vous verrez maintenant `csv-parse` dans les `dependencies` également.

![VS Code montre csv-parse aux côtés de d3 et @types/d3 dans les dependencies de package.json.](/assets/pushing-further/libraries/csv-parse-dependency.png)

Remplacez le code de `main.ts` par ceci, puis relancez `node --watch main.ts` :

```ts showLineNumbers filename="main.ts" {1, 8}
import { parse } from "csv-parse/sync";

const response = await fetch(
  "https://raw.githubusercontent.com/nshiab/data-fetch-lesson/refs/heads/main/temp.csv",
);

const data = await response.text();
const arrayOfObjects = parse(data, { columns: true });

console.log(arrayOfObjects);
```

<Callout type="info" emoji="💡">
    L’option `columns: true` indique à `csv-parse` d’utiliser la première ligne comme noms des propriétés de chaque objet. Au fait, il n’y a pas d’erreur de type cette fois : contrairement à D3, `csv-parse` inclut ses types TypeScript directement dans la bibliothèque, donc nous n’avons pas besoin de les installer séparément.
</Callout>

Si vous regardez votre terminal, vous verrez que cette nouvelle bibliothèque a elle aussi converti notre fichier CSV en une liste d’objets.

![VS Code montre csv-parse convertissant les données CSV en une liste d’objets dans le terminal.](/assets/pushing-further/libraries/csv-parse-output.png)

Et voilà ! Vous avez installé et utilisé une deuxième bibliothèque ! 💃🕺

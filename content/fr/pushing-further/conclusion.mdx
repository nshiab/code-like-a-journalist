# Conclusion

Vous avez maintenant les outils pour créer un projet TypeScript complet ! 🎉

Vous savez organiser votre code avec des fonctions et des classes, enregistrer et lire des fichiers, télécharger des données du web, installer des librairies et définir des tâches Deno pour les commandes que vous utilisez souvent.

Vous pouvez maintenant essayer le projet [Simulateur boursier 📈](/data-projects/stock-market-simulator). Vous téléchargerez des cours historiques, enregistrerez les données localement pour les réutiliser et organiserez votre code en fonctions et en fichiers. Ensuite, vous calculerez comment un investissement aurait évolué au fil du temps.

Ce projet s'appuie sur les chapitres 1 et 2. Si vous préférez commencer par un exercice plus court, essayez le [Calculateur d'épargne 💸](/data-projects/saving-account-calculator), qui utilise les fondamentaux du chapitre 1.

Pendant votre travail, réfléchissez au rôle de chaque partie : télécharger les données, les préparer, calculer les résultats et les afficher. Donner un rôle clair à chaque fonction rendra le code plus facile à comprendre et à mettre à jour.

Les deux projets se trouvent dans **Projets de données**, dans la barre latérale, et vous pouvez les essayer quand vous le souhaitez.

Une fois les projets terminés, passez au chapitre 3, [Analyse de données avec SDA](/simple-data-analysis/tabular-data). Nous commencerons à analyser de grands jeux de données pour répondre aux questions que nous nous posons.

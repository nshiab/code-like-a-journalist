# Conclusion

You’ve completed the SDA chapter! 🎉 You can load and explore tables, transform and summarize data, work with geographic information, and create visualizations. You've also seen how to use AI assistance with SDA while checking the code and results yourself.

<NoticeIntro />

## Choose a project

The **Data projects** section at the end of the sidebar has several ways to practise:

- [Wrangling Census data 🇨🇦](/data-projects/stats-can-census): combine tabular and geographic data to map income levels. This is a longer project, and it requires about 70 GB of free disk space.
- [One billion row challenge 😱](/data-projects/one-billion-row-challenge): load a large CSV file and calculate temperature statistics for each weather station. Try this if you want to focus on aggregation and performance.
- [Web scraping 🔍](/data-projects/web-scraping): extract information from web pages and analyze it with SDA. The project introduces the HTML structures and browser automation you'll need along the way.

Choose the question or technique that interests you most. You don't have to complete every project before continuing. For any of them, take time to inspect the source data and intermediate results, and check that your final output answers your question.

## What's next?

In [Git and GitHub](/git-and-github/git-basics), you'll learn to keep track of changes, share your code, and collaborate. You can use one of your projects to practise these skills. After that, **Going further** explores topics such as refactoring and testing to help you improve your work.
